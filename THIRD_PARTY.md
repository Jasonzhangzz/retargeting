# Source and asset notices

This extraction preserves the current local versions; it does not fetch substitute implementations at runtime.

| Location | Origin and retained purpose |
| --- | --- |
| `retarget/fa/` | Local retarget FA L-BFGS, contact-surface AdamW, and direct trigrasp-style ComFree symbolic acados SQP-RTI |
| `retarget/trigrasp.py` | Local contact-surface AdamW replacement and trigrasp state/rollout utilities |
| `retarget/contact_exploration.py`, `retarget/contact_solvers.py`, `retarget/contact_projection.py`, `retarget/contact_lm_warp.py`, `retarget/contact_memory.py`, AdamW alternating loop | Independently implemented bounded surface projection, sampled contact-set / batched force LM design informed by local scsp-robot `planning/lambda_contact_lm.py` and `lambda_batched_lm.py`; pressure QP and object/hand/scaled-dual splitting informed by [Dexonomy GraspADMM](https://github.com/JYChen18/Dexonomy/blob/main/dexonomy/op/gen_grasp_admm.py). No runtime dependency on either external project; point-contact QP omits torsional moments |
| `retarget/fa/trigrasp_comfree_sqp.py` | Direct CasADi/acados trigrasp MPC with the ComFree soft contact response |
| `retarget/support/` | The used acados discovery, cache and OCP adapter functions from the former planning package; repository discovery and machine paths removed |
| `forceaware/` | Local DexForge ForceAware runtime sources: configuration, time grids, FA loss, targets, interpolation, servo prior, native rollout/adjoint allocation and executor; upstream application/render pipeline and Adam solve loop removed |
| `comfree_warp/` | Complete local custom ComFree runtime and its native adjoints; unused test data and bytecode excluded; runtime source files retain upstream notices |
| `assets/wuji/` | Only referenced right-hand STL and query-point files from local Wuji description and hand assets; XML paths rewritten relative to this repository |
| `assets/wuji2/` | Official [WUJI Hand 2.2 right-hand model](https://github.com/wuji-technology/wuji-description/tree/5c4dfa16917355d073e2e1d7e3d03897b6cf9508/hand2/hand2_2/body), pinned to commit `5c4dfa16917355d073e2e1d7e3d03897b6cf9508`, MIT license retained in `assets/wuji2/LICENSE`. The original MJCF is preserved in `official/right.xml`; `source.json` records aliases and SHA-256 hashes. Local adapter adds six wrist DOFs, aliases anatomical names for the existing grasp interface, selects the native backend's Euler integrator, and generates deterministic full-mesh surface queries including fixed sensor pads. Finger transforms, limits, inertias and actuator parameters retain the official values. |
| `retarget/dexonomy.py` | Independently implemented reader and Shadow → Wuji mapping for an external [Dexonomy](https://github.com/JYChen18/Dexonomy) checkout; reads `raw_anno/*.yaml`, `keypoint.yaml`, and the kinematic joint tree in `right.xml`. No upstream source or template assets are bundled. Upstream templates are CC BY-NC 4.0; generated inputs retain source URL, annotation path and SHA-256 |
| `retarget/grasp_initialization.py` | Input bridge calling the external Dexonomy checkout's original `sample_init_pose`, `HandTemplateLoader._load_data`, `HandObjMatcher.forward`, and `WarpCollisionEnv`. Upstream source is not copied or edited. The bridge packs mapped Wuji inputs and converts original output frames/inward normals for existing ADMM, without reprojection. Input meshes split normal patches at 45-degree sharp edges, retaining exact triangle geometry. On newer Warp it aliases the old device-helper import name to the same public helper. Candidate checks use upstream per-contact loss thresholds and local whole-hand penetration validation; the full filter/padding and evolution pipeline are not invoked |
| `retarget/grasp_template.py` | Local CUDA input adaptation: fit actual Wuji query points, contact normals, root and joint angles to the Shadow contact layout, then to object contacts returned by the original initializer. Primitive cylinder/sphere openings scale with diameter. Each accepted refinement is followed by the original initializer, whose final object pose and surface contacts are retained unmodified. This does not change the shared ADMM/AdamW objective or its architecture |
| `retarget/grasp_explicit.py` | Independent Warp implementation of the equations in ASU IRIS [ExplicitModel](https://github.com/asu-iris/Complementarity-Free-Dexterous-Manipulation/blob/87b320ffb4b40ab4f3aa344371f6e5e8d619aa7e/models/explicit_model.py) and the terminal pose objective in the [Trifinger bowl example](https://github.com/asu-iris/Complementarity-Free-Dexterous-Manipulation/blob/87b320ffb4b40ab4f3aa344371f6e5e8d619aa7e/examples/mpc/trifinger/bowl/params.py), pinned to `87b320ffb4b40ab4f3aa344371f6e5e8d619aa7e`. No upstream Python source is bundled. Local adaptations use real Wuji FK/stiffness, sampled mesh patches, a fixed hold command and initial-object goal, normalized quaternions, and a documented overall cost scaling. Citation: Wanxin Jin, *Complementarity-Free Multi-Contact Modeling and Optimization for Dexterous Manipulation*, arXiv:2408.07855 (2024). |
| `retarget/grasp_runtime.py`, `retarget/grasp.py`, `retarget/grasp_audit.py` | Independent stationary-input construction and result export invoking the same `retarget.fa.solver.optimizer_class` as `run.py`; no separate static CPU optimizer. Post-solve mesh queries use Warp CUDA, and a locally implemented CUDA primal-dual LP checks geometric force-closure certificates with strictly positive normalized coefficients against a CPU HiGHS test oracle. CUDA AdamW retains the existing update and best-iterate formulas and is shared by both entry points |
| `retarget/grasp_simulation.py`, `retarget/grasp_preview.py` | Local post-planning retention test and visualization. Reuses `forceaware.executor.WarpActionExecutor` and native ComFree CUDA dynamics; the object is temporarily placed by an explicitly reported settling-only fixture, then released under gravity with the shared run.py rolling controller. No fixture or external object support is active in the gravity phase. The previous fixed-command test remains an explicit ablation. Grasp physics substeps can be replayed in CUDA graphs with separate fixture-on/off captures; state/control/contact trajectories are checked against uncaptured execution. Live display runs in an independent GLFW process, and offscreen images/video use MuJoCo rendering |
| `retarget/grasp_load.py` | Local CUDA bounded static-load QP for input conditioning: object and hand gravity, Coulomb rays, actual servo command/torque limits, position-command warm input. The nominal state and original Dexonomy surface anchors remain unchanged. This is separate from, and does not replace, the shared ADMM/AdamW MPC. Independent MuJoCo Jacobians/gravity and CPU HiGHS are test oracles only. Physical preload is ramped with a preparation-only fixture, then the unchanged shared controller receives actual state/command feedback |
| `retarget/grasp_reference.py`, `forceaware/workflow.py:RollingController` | Local input-only closing reference from the unmodified original surface contacts, using CUDA joint IK; shared scheduling, warm shifting and actual-command feedback for both run.py and grasp hold. No changes to the common ADMM objective or update rules |
| `retarget/grasp_physics.py` | Local input parameter adapter. Reads resolved contact properties from the run.py reference XML using the existing CPU XML preprocessor; applies optional overrides before GPU model compilation. Records the compiled GPU contact coefficients and supports simulation-only derived XML for archived grasps without changing their original inputs or shared solver |
| `retarget/grasp_primitives.py` | Primitive associations are this project's benchmark settings based on the cited GRASP taxonomy and CMU shape catalog, not metadata supplied by Dexonomy. Special scissors and paired-stick categories are explicitly marked unsupported by single-primitive generation |
| `data/example/` | Prepared right-hand sugar-box experiment from the successful local FA baseline, with MANO overlay, contact guidance and reference arrays; absolute paths rewritten; unused preparation outputs excluded |
| `data/example/sequence/mano_raw/*.npy`, `semantic_contacts.npz` | Corresponding original MANO trajectory parameters, camera/object transforms and semantic vertex correspondences from the same local FA baseline; used by optional noise preparation. No MANO model weights are included |
| `data/dexycb/` | Five different grasped-object MANO sequences from the official DexYCB 20210415 dataset; see its README for provenance, modifications and attribution |

## SPIDER 人形与双手示例（新增）

`data/spider/` 保存 facebookresearch/SPIDER 的源码摘录、公开 retarget_example 中的 AMASS G1 sprint、OMOMO G1 move_largebox 和 ARCTICv2 XHand box_use 示例及模型依赖。固定源码版本为 `44717007de41cbef7565dff7ff9f4453557a2d3d`，数据版本为 `8b0cdf2b24cc86d1c859050c5b0317ddbec59a63`；逐文件来源和 SHA-256 见 `data/spider/manifest.json`。

SPIDER 来源：https://github.com/facebookresearch/spider ，许可证原文在 `data/spider/source/LICENSE`（CC BY-NC 4.0）。公开示例来源：https://huggingface.co/datasets/retarget/retarget_example 。G1 模型保留上游随附的 `assets/robots/unitree_g1/LICENSE`。ARCTICv2 场景引用而未随示例集发布的 XHand 网格从固定版本 SPIDER 源码补齐。原始数据与模型的使用条件仍以各来源为准。

`retarget/humanoid.py`、`retarget/humanoid_admm.py` 和 `retarget/humanoid_mjwarp.py` 是本项目新增的 MJWarp 人形动力学与投影 ADMM 实现；人形姿态跟踪和关键点选择参考上述源码，平方损失、稳定性项和 ADMM 流程是本地改动，详见 `data/spider/README.md`。
