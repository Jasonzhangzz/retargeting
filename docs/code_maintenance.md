# 方法与参数维护

源码树仅保留 `solver/cem.py` 和 `solver/graspadmm.py` 两个求解方法。`solver/base.py` 只定义公共数据契约和两种方法的调度，不实现算法。

CEM 的采样、patch、穿透、五步响应与初始化默认值集中在 `cem.DEFAULTS`。GraspADMM 的原生操作、GPU适配、初始化与内部 QP 默认值集中在 `graspadmm.DEFAULTS`。正式入口无算法覆盖参数和额外 preset；设备、输入输出与批量资源可显式选择。

几何、模型、接触、积分、数据读取和评测作为工具模块保留。初始化 IK 与模型标定不是可选抓取方法；数值测试的参考后端与缩小预算不写入生产配置。上游源码及许可证保留来源信息。
