# contact_motion_v3 联合标定

默认入口为网页“开始 17 动作联合标定”。SDK 八动作仅建立初始化和参考坐标；其数据不会进入新协议的训练 buffer。原记录、旧协议恢复、已训练权重预览继续兼容。

训练、独立复测各 17 个动作，每动作 5 秒，共约 170 秒。动作顺序由 `static/calibration-contact-targets.json` 定义，包括原来的 16 个接触动作，以及五指保持伸直、张开并拢两次。握拳目标为各 distal 到自身 MCP 下方掌面；折叠目标为各 distal 到自身 proximal 掌侧。

新增的非接触动作使用 `schedule_revision=contact_motion_v3_spread_v1` 和显式 `motion_schedule`。其轨迹事件只作并拢证据，五指 EMF 权重均为 1，不施加指尖接触等式。允许最后一次并拢后停住，无需额外第三次张开。未完成的旧会话在原 32 个窗口末尾追加训练和复测各一窗，保持正在采集的动作序号和全部原始行；已完成的旧 16 动作记录仍可直接拟合。

采集区上方始终显示训练／独立复测完成数、内存和落盘帧数、实际保存路径，以及原始标定 JSON 下载。所有必要窗口完成后，用户点击“开始拟合”并选择训练方法；采集完成不再自动启动拟合。拟合入口不受短暂显示帧过期影响，仍由工作进程检查记录完整性。

主按钮随采集状态指向下一步：尚缺最后一窗时显示“开始最后一次复测（5 秒）”，点击后采集所示动作；最后一窗完成后立即切换为“开始拟合”。未开始拟合时明确列出尚缺动作，不以无反馈的禁用按钮暗示后台处理中。提交任务、数据快照、预处理、GPU 编译、训练和验收进度显示在主按钮旁。后台保存报告实际已编码／总帧数与已提交文件数；编译采用不定进度，不虚构完成百分比。

## 采集与证据

- SDK 初始化回放及冻结参考模型在后台准备，控制接口立即返回，不扩大原有控制超时。
- 标准 MANO 区域中心轨迹用于选帧，属于几何参考代理，不是实测皮肤接触距离。平滑后以位移显著性识别局部极小值及松开；不按固定时间划分两次动作，不规定速度或保持时间。
- 每次事件选取真实采样帧，标记 `contact_constraint_source=trajectory_assumed_contact`。触觉允许未知，不伪造双侧触觉证据。
- 五秒窗口不足两次时保留所有原始样本及已确认事件，补录新的五秒窗口，只补缺失事件。重做整组也保留原始样本，旧样本标记 `training_eligible=false`。
- 窗口内超过 250 ms 的采样缺口仍将轨迹分段，禁止跨缺口推断松开；保留窗口剩余采样机会，结束时只补缺失事件。已有两次完整事件时，后续中断或恢复不会再要求补录，而是进入下一动作；原始数据和事件标签保持不变。
- `capture_pass` 和 `partition` 为 train/validation；初始化为 initialization。`window_id` 隔离时序历史；`contact_event_id` 标识两个独立事件。扩展流程的训练和验证都必须完成全部 17 动作的两次事件；旧 16 动作完整记录仍可读取。
- 新采集启动前备份原 motion-capture.json 到 capture-history。新协议另存 contact-motion-v3.json；取消、补录和恢复均不覆盖旧训练权重。
- 后台按行使用 C JSON 编码，每 256 KB 主动让出线程；一份编码结果用于三份原子保存，保留严格有限数检查及原有 JSON 格式。下载按块读取已提交文件，不再分配整份记录的字节副本。前端只有轨迹实际变化时才重建图形。

## 区域、模板与损失

新增四个虚拟 `palm_mcp_*` 几何区域，保留 20 个触觉分区、460 个 SID 和原 Delta 输入维度。区域及固定面片/重心坐标在优化候选之前确定。

模板只使用训练事件，在标准 MANO 上调整受限关节姿态，同时优化接触位置、对向法向和 EMF 指尖方向。模板包含解出的姿态、锚点、法向、穿透及不可行残差；随后冻结。验证数据不能选择模板、修改锚点或参与归一化/早停。

多指接触图使用冻结参考的连通树，另给缺少的拇指边添加 0.25 权重的软吸引。不会把多个手指压到同一个拇指点。位置/法向权重保持 320/40，按动作、事件、边归一化；两指/多指对指观测相对于掌面/握拳/折叠为两倍。非指定手指 EMF 观测损失权重为零，动作标签不输入网络。

所有训练帧常驻 GPU 完全混训；关节 Delta 与几何联合更新。MCP 接触允许相应指根参数参与几何辨识，中指指根仍是固定坐标基准。指定手指和接触表面直接更新，其他耦合表面使用 0.95 EMA。几何不恢复硬形状裁剪。运行时权重固定，不在线学习。

## 验收与诊断

- 独立完整复测检查全部 16 动作：真实原始区域三角面间隙、法向、连通性及所有拇指优先边的距离；不能用模板锚点间隙替代真实三角面距离。
- 平均间隙 ≤3 mm、最大 ≤5 mm、穿透 ≤2 mm，保留逐动作 EMF、骨架、碰撞和 60 秒性能门槛。
- 接近/释放采用完整轨迹的 EMF 验证，并在每个有效窗口选三个分散的远离接触时刻作原始三角面检查：相对接触时必须重新打开至少 2 mm，防止始终吸合。报告注明抽样范围。
- SDK 初始化帧另作辅助伸直/并拢诊断，不声称它们是新采集的独立复测。
- 曲线增加几何/策略裁剪前梯度范数、学习率、有效关节限位饱和比例。既有 Delta 输入已标准化，输出弧度在关节坐标中叠加，不做单位向量归一化。

测试使用合成轨迹和明确标记的重标签 SDK fixture，只验证实现，不代表新动作的精度或真实重新训练结果。真实精度和性能须完成新协议采集后另行报告；失败候选不自动应用。
