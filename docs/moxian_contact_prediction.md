# 手套 MANO 接触预测对照

运行 `.venv-moxian/bin/python -m moxian_web.server --port 8890`，打开
<http://127.0.0.1:8890/#contactPrediction>。推理权重由本机通过
`MOXIAN_CONTACT_CHECKPOINT` 提供，仓库不附带训练检查点。

网络由独立 CPU worker 加载，不阻塞串口采样。默认使用 `.venv-contact/bin/python`；
可通过 `MOXIAN_CONTACT_PYTHON` 和 `MOXIAN_CONTACT_CHECKPOINT` 更改路径。
预测 worker 不占用 CUDA，不执行训练，也不向手套发送触觉反馈。

选择 MANO 模型可以看到 778 顶点预测热图；黄色点仍由真实触觉触发。
“网络预测 × 实测触觉”面板并排显示采样到 460 个触觉位置的接触概率、
同帧实测二值接触／原始 ADC、误报与漏报。三个图采用同一手套掌面展开轮廓，
使用当前手型静止网格及 SID 三角面重心坐标投影，五指和腕部有位置标注；悬停显示部位与 SID。
展开轮廓保持固定，握拳时也能查看掌心和指腹上的触觉位置。红色是误报，蓝色是漏报，
绿色是命中。模型预测接触概率，没有训练压力回归，不能将其当作预测 ADC。

输入来自 `raw_official_pose_axis_angle`：这是触觉修正之前的官方骨架到 MANO
旋转映射。它采用 `flat_hand_mean=True` 的绝对局部轴角，按 MANO 原生关节顺序，
左手按训练约定镜像为右手。触觉修正后的 `pose_axis_angle` 不会作为网络输入。
手套目前没有世界坐标腕部跟踪，因此 pose51 中腕部固定为零平移、单位旋转；
这会缺失训练数据中的腕部运动信息，页面明确显示该条件。

实时预测使用最近 8 个不同时间戳的有效 MANO 帧。输入间隔超过 250 ms、
手侧、几何或标定版本变化会清空历史，重新收集 8 帧。
重复轮询不增加历史或累计指标。真实触觉仅在预测之后用于比较；它来自该 MANO
帧对应的原始参考，而不是请求时的最新触觉。参考未就绪、未去皮或时间差超过
25 ms 时保持未知，不计成“无接触”。默认顶点／SID 阈值 0.52，帧级阈值 0.50。

778 顶点概率通过现有固定三角形及重心坐标采样到 SID。当前／累计示意 F1
使用这套映射；只有经过独立位置核验的 SID 才进入“已核验位置 F1”。
位置核验为 0/460 时，该项为空，不以解剖分区确认冒充位置核验。
无接触的空预测／空真值不定义 F1，页面显示“—”。

“重置统计”只清空预测比较计数，“重载网络”只重启 CPU 推理进程。
两者不修改手型、触觉去皮、映射或标定。现有会话录制额外保存
`contact_prediction`，其中保留预测与同帧参考；加载 JSONL 回放时可检查当时的结果。
