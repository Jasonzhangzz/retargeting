# Moxian → Wuji2 GeoRT

打开网页，选择 **Moxian／Wuji2 对照**，展开 **GeoRT · 动作录制与网络训练**。

1. 完成六动作手型标定并应用，等待实时模型。点击“开始录制动作”，自然伸展、弯曲每个手指并对指，手动停止。后台逐帧接收，切换视图或浏览器后台运行不影响录制。
2. 可录制多段，选择兼容数据后选择训练模式并点击“重新训练并替换 GeoRT”。“官方目标”保留原始loss；“接触约束”增加下文描述的真实网格损失。两种模式都禁止机器人手指负向屈伸采样及输出，不宣称整条流程完全复现官方。建议另录独立动作作为评估集。默认 FK 与网络各200轮；首次生成100,000组机器人关节样本并训练 FK，后续相同配置复用 FK 缓存。
3. 每次训练成功后替换唯一的 `models/current` 模型；若正在使用 GeoRT 则自动重载预览。失败或取消保留原模型。也可点击“启用网络预览”。GeoRT 直接输出20个手指关节角。可回放所选一段动作、暂停和拖动进度，点击“返回实时输入”结束回放。
4. 选择未参与训练的独立录制，点击“用所选独立数据评估”。报告工作空间覆盖、方向保持、对指距离、限位违规与 CPU 推理时间。没有配对机器人真值，不将这些指标解释为关节角真值误差。

## 环境与命令行

`bash scripts/setup_geort.sh` 补齐现有训练环境中的 Open3D 等依赖；网页服务环境需要 NumPy。默认训练解释器为 `.venv-contact/bin/python`，可设置 `MOXIAN_GEORT_PYTHON`。完整训练需要 CUDA；网页服务与串口线程不加载 PyTorch。

```bash
.venv-contact/bin/python -m retarget.baseline.geort.cli train \
  --datasets RECORDING_ID_1 RECORDING_ID_2 --epochs 200 --fk-epochs 200

# 明确改变训练目标；机器人采样及输出仍禁止反伸。
.venv-contact/bin/python -m retarget.baseline.geort.cli train \
  --datasets RECORDING_ID --mode contact_v1 --epochs 200 --fk-epochs 200

.venv-contact/bin/python -m retarget.baseline.geort.cli evaluate \
  --model MODEL_ID --datasets INDEPENDENT_RECORDING_ID

# 对真实原始EMF会话，用匹配的Moxian标定重建；保留原文件与配置哈希。
.venv-contact/bin/python -m retarget.baseline.geort.cli import-raw \
  --recording SESSION.jsonl --profile CURRENT.json --id IMPORT_ID
```

`--root` 放在子命令前指定输出目录。`train --smoke-test` 明确标记为缩小样本的功能测试，不能作为完整复现结果。网页只使用完整样本设置。取消保留配置和日志，删除未发布权重，不替换已启用模型；只有成功完成的模型能启用。

## 复现边界

官方基线为 `facebookresearch/GeoRT@fb2075e2a3272be372016580c0b6ebd6120228f0`。`retarget/baseline/geort/upstream` 保存未修改的网络、数据集、损失、归一化与训练参考文件以及 SHA256，保留 CC BY-NC 4.0 许可证。适配代码位于 `retarget/baseline/geort`；Web服务接口位于 `moxian_web/geort_service.py`。

网络为逐指 `128 → 128` 的 LeakyReLU＋BatchNorm MLP。FK 使用 Adam `5e-4`、batch 256、200轮；IK 使用 AdamW `1e-4`、batch 2048、200轮。人手各指独立做1 mm体素降采样（CUDA实现Open3D legacy的分格及质心语义），再各自重采样至50,000点；保留上游 `randint(0,n-1,K)` 行为。上游 `n=20000` 参数并不决定数据集长度。

训练公式按官方源码实际行为执行：方向＋80×Chamfer＋0.1×曲率＋1×对指，碰撞项为零；对指遍历所有指对。曲率扰动2 mm，方向扰动1–11 mm，对指判定15 mm。测试直接执行原始训练文件的损失块，对比损失、梯度和一次 AdamW 更新。

输入为标定后腕部局部坐标的五指指尖，左手按既有规则镜像。仅旋转和消除腕部平移，不拟合尺寸或缩放。机器人 FK 标签由当前 Wuji2.2 MuJoCo 模型的五个 tip site 计算，腕部固定，屈伸关节下限与物理伸直位0°取交集；此处用CUDA批量执行同一原生模型的FK替换官方 SAPIEN FK 采样器，随机角结果与MuJoCo逐帧FK核对。没有用 SLSQP/CEM 生成机器人监督标签。官方模式没有追加触觉损失或碰撞优化；两种模式推理时均不追加求解或输出滤波。

## 采样姿态域修复（2026-11-16）

原生机械范围允许PIP／DIP等轴约60°反伸；此前只收紧到Glove的10–20°工程容差仍会生成反折。用户指出样本14105（食指PIP −1.80°、DIP −17.73°）后，现已将**四指MCP屈伸／PIP／DIP及拇指MCP／IP**的采样和网络输出下限统一设为Wuji2物理伸直位0°。Glove标定反伸容差仅作为源模型元数据保存，不再放宽机器人样本。拇指CMC和外展轴允许的负角属于不同运动，仍保留原生范围。

两种模式都直接在此域内均匀生成FK姿态，不裁剪旧姿态。配置记录 `robot_sampling_policy=nonhyperextended_flexion_uniform_v2`、`output_domain.robot_extension_policy` 及 `fk_cache_key`；旧域标签和神经FK不会作为新域缓存复用。IK输出使用同一有界映射，推理不额外夹角或求解。官方loss公式保持不变。

参考v5会将任何含负向屈伸的完整姿态连同五个指尖一起排除；14105已成为回归用例。成功发布时清理旧FK、机器人目标和参考姿态缓存，只保留当前版本；不删除原录制和源几何预处理。旧模型在新训练成功前保留，不能给旧权重直接套新角度映射。

散点使用固定毫米尺度，切换参考或手指不重新适配点云大小。只缓存pose，点击时渲染，并显示该手指的各关节角。限制关节角不意味着指尖三维包络各方向都必须缩小：保留的正向屈曲及外展仍可能到达原来的部分边界。

## 生成姿态实际清理

当前FK表已实际删除穿透超过5 mm的52,352条记录，只保留47,648条合格完整姿态；旧FK／参考、历史预测姿态表与旧预览报告已删除。现有模型权重不变，配置保留原FK训练100,000条的事实，并单独记录 `retained_robot_samples` 和清理摘要。

后续训练在写盘前检查整手姿态和原生网格，仅保存通过的关节角、指尖标签与几何检查结果。FK训练和IK目标均读取此合格子集；缓存指纹包含筛选策略及几何代码。`robot_samples`及文件名中的数字表示提议预算，实际存储行数为 `retained_robot_samples`。改变几何检测会使证明和缓存失效，不复用旧的未筛选FK权重。源录制不改动。

## 数据、接口与恢复

### 接触约束模式 `contact_v1`

此模式是用户授权的改进版，不属于官方复现。原生机器人模型、指尖坐标适配、FK缓存和官方损失函数保持可用；训练时计算额外的真实网格损失。两种模式都在下述有界姿态域中直接均匀采样，并将同一边界写入网络结构；`--mode official` 保留原始loss。网页命令 `geort_train` 新增 `mode`，省略时为 `official`；网页模式选择器显式默认选择接触约束。

机器人屈伸下限为物理伸直位0°，范围与Wuji2原生机械限位取交集。源Glove仍使用保存标定的 `joint_limit_policy`，允许的轻微负角保留在源监督中，不直接传给机器人采样域。输出域作为网络有界映射保存于 `output_domain`，保持原生归一化供神经FK使用。

源监督读取同帧21节点及关节角，按各关节的物理伸直偏移计算**有符号**PIP／DIP弯曲；轻微负角不会取绝对值变成屈曲。额外损失使用可微原生FK的三段骨轴和原始机器人网格。全手穿透覆盖跨指、非相邻同指及非连接掌面，机械连接区域按已有原生碰撞策略排除。每帧取最大穿透，避免大量无碰撞部位稀释一个穿透。训练用固定曲面采样并刷新连续三角形最近见证点，对两侧刚体运动传播梯度；仍需用更密集的独立几何查询验收。

源distal区域间隙≤2 mm或发生网格交叠时标为接触意图，4 mm退出；超过250 ms断流重置滞回。接触训练取该标签与官方指尖距离<15 mm的并集，避免原版触发的对指在新增约束中漏掉。源网格原件不修正，交叠作为意图监督，将机器人指定掌侧distal表面目标设为接触间距0，并优化相对法向；没有接触意图时不施加表面吸引。预处理保存源文件SHA256及缓存指纹，可复用。

额外损失（`pair_balanced_contact_first_v2`）为 `10×penetration + 2×surface_contact + 0.2×surface_normal + 0.5×bone_direction + 0.05×bending + 0.5×flat_pose + 1×pinch_position + 5×flat_direction`。`pinch_position`在官方15 mm触发帧上，使用真实FK的指尖距离平方／(15 mm)²，把原来以米平方计、数值较弱的指尖聚拢目标显式归一化；它与表面贴合及穿透共同优化，指尖site距离不被当成表面间隙。接触距离与法向先在每个有标签指对内部求平均，再按指对等权平均，避免持续时间较长的相邻指接触稀释较少的拇指对指。接触和防穿透权重同步提高10倍，保持二者的相对比例；不以允许穿透换取距离变小。闭合动作中，参与接触的手指骨轴、弯曲及近伸直姿态损失降为原来的0.1，允许机器人因指长不同调整姿态；整手四指PIP／DIP均在±10°内时，形状／摊平项同步增强10倍，以保持与新增接触项的相对强度。另在整手摊平帧单独计算末节骨轴方向项 `flat_direction`（15°归一化），不将其稀释到三段骨轴的平均中；闭合帧该项为0。该门控完全依据源数据，不允许预测姿态自行逃避损失。穿透按0.5 mm、间隙按2 mm、相对法向按30°、骨轴方向按15°、屈伸角按10°归一化。小于10°的近伸直指单独计算flat_pose。官方基础损失同时保留；日志的 `collision=0` 仅表示基础官方项未启用，实际网格惩罚记录为 `penetration`，不能混淆。配置保存实际权重和归一化。

此模式不执行独立逐指重采样。以整帧五指15维指尖的1 mm联合网格去重后，整帧重采样50,000条，保持同帧关系。每个主批次2048帧，额外几何批次64帧（32接触、16近伸直、16均匀；接触槽位先覆盖每个有效指对，其余按拇指对指2倍概率抽取），全部来自同一训练会话集合。几何损失前向使用推理BatchNorm统计并保留梯度，避免偏置小批次污染运行统计。AdamW学习率1e−4，默认200轮。训练、FK及网格查询使用CUDA；小规模整帧索引构建与文件清单在CPU执行。

2026-11-16执行优化与目标域修复：接触约束模式的Chamfer机器人目标改为原始FK样本中同时满足当前 `output_domain` 和最大自穿透≤5 mm的完整姿态；先筛角度，再只对剩余姿态做密集网格检测，原生全范围神经FK缓存仍可复用。当前100,000组原样本中872组符合输出域，495组通过穿透筛选。没有通过裁剪关节、缩放指尖或新造随机姿态扩充目标。目标索引、逐姿态深度、有效标记、原始样本SHA、机器人／代码／输出域指纹保存到 `robot_contact_targets/`，并将实际目标集写入模型配置。5 mm只用于参考样本筛选；训练穿透项仍把穿透推向0，0.5 mm是归一化尺度，不是穿透豁免阈值。

接触标注以16帧批量执行原始distal曲面顶点／面心距离和带符号穿透查询，保持2 mm进入／4 mm退出、穿透>0.1 mm接触意图及250 ms断流重置规则。每帧独立BVH，复用CUDA graph；没有计算未使用的法向误差或生成优化器见证点，按批一次回传所需结果。已核对6,333帧的63,330个指对标签与旧实现完全一致，代表帧的间距和穿透查询误差为0。

几何loss复用查询缓冲，仅为最大穿透见证点保留反向图，保留并列最大值的平均梯度；表面接触和法向仍参与反向传播。Chamfer在无梯度区查找最近点，再对真实坐标差反传；重复抽中的机器人目标按原次数加权，不改变最近点目标或权重。逐项loss一次回传到CPU；官方模式保留原版Chamfer路径及固定随机数顺序。优化测试覆盖固定输入下损失／梯度、并列最近点／最深见证点、缓存复用、跨帧隔离及旧官方损失和一次优化更新一致性。

成功训练仍只保留唯一 `models/current`；配置明确 `training_mode=contact_v1`，网页模型列表和机器人画面标为“接触约束”。失败／取消不替换已发布模型。低loss和受限角度不能证明完全无穿透，评估报告会保留不达标帧。

目录 `output/moxian/geort/`：`recordings/<id>/` 保存点云、时间戳、同帧关节角、骨架、源模型、拓扑及清单；`models/current/` 保存唯一已发布模型的配置、最新 last.pth、损失及评估；`training/<run_id>/` 保存进行中或失败任务，成功任务只留下轻量状态；`fk/<hash>/` 缓存真实FK标签与神经FK；`active.json` 保存已启用模型。

每段绑定设备、手侧、标定、几何及坐标变换；不同源不能合并。源变化或断连结束录制并保留数据。回放由保存模型和同帧关节角重建 Moxian 网格，使用真实时间间隔，另行显示原录制时间戳。

`POST /api/command` 新增 `geort_record_start/stop`、`geort_train/train_cancel`、`geort_model_select`、`geort_evaluate`、`geort_replay_load/pause/seek/stop`。列表接口为 `GET /api/geort/recordings`、`GET /api/geort/models`；`/api/state.geort` 提供录制与任务状态，`wuji2.playback` 提供回放状态。训练和评估为独立进程，文件锁限制并发训练；重启网页可恢复任务状态及已启用模型。

网页支持批量删除所选录制和删除所选模型，包括失败或取消的模型。删除当前启用模型会卸载该网络、停止其预览，并显示缺少模型；不会自动切换求解器。录制／保存中的数据、回放中的录制和后台任务使用中的资产不能删除。删除录制不级联删除已训练模型，也不删除共享 FK 缓存。CART 面板提供同等删除操作。

采集面板仅保留三维散点图，已移除覆盖进度条、百分比／均匀度表格、投影热图和“追逐未覆盖区域”的提示。绿色独立显示录制的1 mm去重指尖点（显示为网格中心，单指最多2,000点），参考外的采集点也保留；灰色显示原始训练FK文件中合格姿态的真实指尖坐标（非5 mm网格中心），可以独立隐藏。两者共用掌部坐标，不做尺寸缩放。机器人与人手尺寸、关节范围和关节耦合不同，灰点不是人手必须覆盖的目标。

参考直接读取当前已发布模型指定的 `fk/<fk_cache_key>/kinematics_<robot_samples>.npz`，保留同时满足**当前IK网络输出上下限**、**禁止负向屈伸的边界**和**最大自穿透≤5 mm**的完整姿态。旧模型没有 `fk_cache_key` 时兼容原 `robot_key`。任一关节超出允许范围，该完整姿态的五指点一起排除。无效查询另行排除，不增加随机样本，也不通过裁剪关节或缩放指尖伪造合格姿态。旧官方模型的原生大反伸样本也会从参考中排除；此图是有限姿态参考，不是完整可达空间估计。

原生网格全部顶点和面心执行双向穿透检查，覆盖跨指、掌面、同指非相邻部位，沿用连接关节机械重叠区域排除规则。5 mm阈值仍允许一定穿透，不是无碰撞证明，也不约束人体关节耦合。独立进程在CUDA可用时使用GPU；缓存按训练样本SHA、原生资产、检测代码及输出域区分。更换输出域自动失效；缺少原始训练样本时明确等待。API兼容保留旧覆盖数值和投影字段，网页不再将它们显示为动作完成进度。训练FK样本、训练目标及模型权重不会因参考筛选而改动。

可多选相同设备、标定及坐标约定的录制，点击“叠加所选录制散点”。累计统计为所选录制并集，重叠网格只计一次。每次成功开始新录制都会清空叠加基线、绿色散点和已采集单元计数，仅累计本次动作；Wuji2姿态参考保留。要查看多段累计分布，可在停止并保存后重新叠加所选录制。更换标定会使旧覆盖不兼容；删除基线数据会清空基线，避免仍计入已删除数据。后台重启后需要重新选择基线，单段覆盖摘要保存在其 manifest。

四种拇指对指分别显示15 mm以内的帧数、时长、不同接近位置及持续至少100 ms的接近次数，20 mm退出；超过250 ms断流会中断接近计时。这是 GeoRT 点目标采集提示，不表示真实网格表面接触。

```bash
.venv-contact/bin/python -m retarget.baseline.geort.cli control geort_recordings_delete --data '{"ids":["录制ID"]}'
```

训练／评估和 CART 预处理持有 `assets.lock` 共享锁，删除持有独占锁，并兼容已有 GeoRT 训练锁。命令行删除必须经过 Web 服务，以便卸载正在预览的模型。

GeoRT 仅驱动虚拟 Wuji2，不保证自碰撞、物体间距或触觉匹配；页面不会伪造接触约束验收或传感器状态。

## 表面接触与穿透诊断

在 GeoRT 面板展开“网格穿透与表面接触诊断 · 只读”，点击“开始表面诊断”。逐一显示拇指与其余四指的 distal 表面间隙、两指各部位的最大采样穿透深度、最近见证点的相对法向误差，以及全手最大采样穿透。启用 GeoRT 时使用同一网络结果携带的源网格和20个关节角，通过原生机器人 FK 重建表面；其他求解器或 GeoRT 尚无有效结果时仅诊断源 Glove，机器人列明确显示未诊断。实时与回放均可用，暂停回放保留该帧结果；断流或上下文变化时不继续显示旧数值。

诊断在独立进程运行，CUDA 可用时使用 GPU；一次只计算一个抽样展示帧，不向录制队列插入或删除帧。停止诊断释放子进程。首次启动包含模型及内核初始化，网页显示初始化状态；后续显示计算时间、结果年龄和源时间戳。状态位于 `/api/state.geort.diagnostics`，开关命令为 `geort_diagnostics_set`，参数 `enabled` 必须为布尔值。

表面间隙使用完整指定区域三角形，双向查询其全部顶点与面心，得到最短间隙的采样上界。法向为同一见证点处插值的原生表面法向。穿透使用原始皮肤／机器人网格带符号顶点与面心查询，排除相邻骨段连接缝，保留跨指及非相邻区域。默认间隙≤2 mm、穿透≤0.1 mm且法向误差≤30°标为“接触近邻”；穿透优先标红，即使无符号间隙为0也不标为接触。采样可能漏检小面积接触或穿透，不是连续三角形无交叉证明，也不等同于抓取稳定性验收。

保留官方训练目标，`collision=0`仍表示未启用碰撞损失。诊断不修改录制、权重、关节角或源网格，不将检测到的穿透修正为接触。可离线审计真实录制，输出 JSON：

```bash
.venv-contact/bin/python -m retarget.baseline.geort.diagnostics \
  --recording RECORDING_ID --model current --stride 50 --max-frames 64 \
  --output /tmp/geort-surfaces.json

.venv-contact/bin/python -m retarget.baseline.geort.cli control \
  geort_diagnostics_set --data '{"enabled":true}'
```

本节原始官方模型run_id=`20261116_gpu_mcp_rng_v2`，其历史权重已清理，比较输出和诊断元数据保留。使用5604帧真实录制；先完成100,000组FK采样及200轮FK训练，再复用该缓存完成200轮IK（157.9秒），GPU为RTX5060Ti。机器人随机留出1000组关节的神经FK误差均值1.92 mm、最大7.16 mm。CUDA真实FK与MuJoCo随机256组关节的最大坐标误差2.98e-8 m；五指1 mm体素质心集合与Open3D一致。GPU体素排序不同于Open3D无序哈希表，不承诺整个训练逐位相同。

最新权重的摊平诊断：同一训练会话中选取源PIP/DIP骨段夹角最小的100帧，源夹角平均2.41°。机器人四指PIP/DIP小于−10°的比例23.125%，平均绝对屈曲角38.54°，仍未通过自然摊平验收。中指distal与源骨段方向误差均值25.39°。这是训练会话内诊断，不是独立泛化验收。用户选择保留官方loss，不添加摊平／自然屈曲约束。结果见 `output/moxian/geort/orientation_report_20261116.md` 和 `continuity_audit_20261116.json`。

FK采样与官方代码一致，直接在原生关节范围均匀生成，不执行自碰撞拒绝采样。该数据监督的是“给定关节角→指尖位置”的神经FK，不是给IK指定自然姿态的配对标签。仅过滤FK数据也不能保证IK输出无碰撞：逐指工作空间仍无法表达同帧整手的避碰约束，IK输出也不被限制为采样表中的某一个完整姿态。反折和穿透是两个不同条件，未碰撞的姿态同样可能反折。当前Wuji2原生PIP下限约−60°；若要排除该分支，需要另外改变允许姿态域或增加姿态／表面约束，属于严格官方复现之外的行为。该节历史运行尚未启用这些修改；2026-11-16采样修复后，两种训练模式均启用下述有界姿态域。

再次核对实时配对帧，离线网络复算与网页20关节角最大差3.1e−6 rad，没有发现显示层额外翻转。该抽查时源手处于弯曲状态，不能当作新的摊平验收；同帧原始数值保存于 `live_orientation_diagnostic_20261116.json`。当前权重SHA256仍为 `3be6c9c4b1bf5def3a7afb1ed83d91d5fe45c89402e44eb715170dd52ceb327b`。

训练公式仍为 `total = direction + 80×chamfer + 0.1×curvature + pinch`，均按最小化优化。direction是负方向余弦，理想为−1，total为负正常；其余项趋近0。collision固定为0代表原版未启用，不代表没有穿透。total不能代替独立接触／方向／真实FK验收，也不应跨不同坐标和数据分布直接比较。神经FK、IK、真实机器人FK批量采样及体素预处理使用CUDA；实时网络推理默认CPU。

模型发布先完成临时训练再替换唯一 `models/current`。成功后更新 `active.json`、清理旧模型、逐轮及旧任务权重；失败或取消保留原模型和诊断日志，删除未发布权重。后续每轮只覆盖最新 `last.pth`。当前辅助FK权重及其可复用缓存保留，旧版本FK权重删除。配置、数据、损失日志和诊断报告保留。


方向／曲率约束作用于 `F(p)=neuralFK(IK(p))` 的局部指尖映射，不约束distal朝向或相邻录制帧的关节角；训练逐指重采样后打乱，未使用时间顺序。连续但反折的关节分支可能保留。CPU与CUDA均直接执行官方loss代码块，逐项比较损失、梯度和一次AdamW更新。方向扰动长度严格沿用官方CPU随机生成后传GPU，避免固定seed下换随机数流；该标量采样不改变GPU FK和体素预处理。

### 点选参考姿态

采集散点图中的Wuji2参考点现在可点击。每个可点击点保留原训练FK样本编号，点击后，浏览器才根据该样本的20个关节角与原生模型计算FK并渲染，右侧独立Wuji2视图显示整手，所选手指及对应指尖为金色。它不通过已训练网络反求姿态，也不切换当前求解器或暂停录制。

橙色表示该手指所在5 mm单元尚未出现在当前叠加录制中，灰色表示该单元已采集；绿色仍独立绘制所有采集点。“仅显示未采集参考点”和“查看下一个未采集点”可用于逐个检查。蓝环标记当前点，拖动散点图仅旋转视角，拖动右侧模型可查看其他角度。采集过程中，已选单元的状态随新数据更新。

参考每次最多显示2000个实际FK样本，只缓存对应的20维关节pose；不缓存逐姿态的连杆变换、变形网格或渲染结果，完整筛选集合和覆盖统计不抽样。点的坐标与姿态来自同一原始样本；旧参考没有对应姿态时需要重建。参考变化、设备或标定变化会使旧选择失效。橙／灰判断仅针对所选手指的空间单元，不代表该整手姿态已被采集；有限机器人姿态也不保证人手可达。当前参考仍沿用原有输出域和5 mm穿透筛选标准。
