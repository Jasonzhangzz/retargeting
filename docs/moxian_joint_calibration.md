# moxian 连续联合标定

默认入口是 MANO 面板的“开始连续联合标定”。首次先按骨架面板完成官方八动作初始化；已有匹配记录直接复用。随后依次采集五指活动范围（每指 9 秒）、拇指对掌（12 秒）、四组对指（每组 15 秒）及张开／并拢复测（各 4 秒）。纯连续采集共 125 秒，另加动作准备时间。触觉需先去皮。

每组运动重复三轮。前两轮辨识参数，第三轮完整留出；末尾复测仅验证。对指每轮五秒，跟随“分开、接近、轻触、释放”的提示及左右手示意图。每轮轻触至少需要三帧同期双侧触觉证据；缺少证据、采样中断或活动范围不足时暂停，仅重做当前一轮，已完成轮次保留。点击“继续第 N 轮”恢复，也可选择“重做整组”。重启可恢复匹配设备及初始化版本的未完成记录，无需重做八动作。

原始观测使用独立缓冲，采集不依赖 MANO 渲染帧率。真正超过 250 ms 的数据缺口仍会暂停，恢复时清空旧时间戳；每秒至少 15 帧及触觉质量要求保持不变。

腕部坐标转换与骨架回放按帧显示进度和本阶段预计剩余时长；参数辨识按实际迭代速度估算。采集显示剩余动作时长（不含准备与拟合）。回放不再使用固定 45 秒／300 秒总时限，连续 120 秒无进展才报错，且可随时取消。

## 参数与优化

个体参数版属于参数辨识。Adam（学习率 0.01）先拟合 MANO 的 10 个 betas 和安装对齐，再冻结 betas 辨识额外固定几何，最后用有界分块 LM 精修。新增 43 个几何坐标：15 个骨段轴向 log 比例、5 个宽度及 5 个厚度 log 比例、除中指外四个指根的三维偏移、拇指三条 CMC 轴各两个倾斜坐标。中指 MCP 固定掌部平移基准；不拟合额外的原始数据尺度。

骨段比例范围为 1/1.5–1.5，宽厚比例为 1/1.6–1.6，指根偏移每轴 ±8 mm，拇指轴倾斜每坐标 ±10°。通过测量残差的条件几何 Jacobian 和主元 QR 报告弱方向，对弱坐标保留先验值。此诊断以当前姿态和安装参数为条件，不代表仅靠末端传感器能唯一还原全部解剖参数。

固定几何使用 SMPL-X 的姿态修正与 LBS，显式共享关节中心；个体骨架导出在运行目录，SDK 原文件不变。MANO 不具有厂商额外的掌部 CMC 平移自由度，因此个体骨架固定非拇指的额外 CMC 自由度，并保留各指可表达的关节旋转。个体 URDF 和 MANO 绑定一起使用相同的坐标变换。

对指训练的位置权重为 320、法向权重为 40；对指观测总权重是普通动作的两倍，按动作归一化，不随重复帧数增长。只有轻触区间的真实双侧证据或原八动作的明确静态接触指令参与接触等式。实时骨架在逐指 SLSQP 后，仅对唯一、双侧触觉有效、间隙 ≤12 mm 且法向相向的指腹进行联合 SLSQP；不使用采集动作标签。

## 验收与存储

完整记录在设备目录的 `motion-capture.json`，协议为 `geort_motion_v2`，包含原始 EMF、同期 ADC、轮次、运动阶段和训练／验证分区。训练按运动阶段覆盖抽样，所有第三轮帧与最终复测都参与留出验证。原八动作仍可用于离线诊断。

候选必须通过传感器定位、四组对指、张开并拢、完整第三轮、接近释放、实际骨架及 MANO 路径检查。对指平均间隙 ≤3 mm、最大 ≤5 mm，曲面穿透 ≤2 mm；预算耗尽的候选不会应用。个体骨架分别回放纯 EMF 与真实触觉路径。骨架逐指 RMSE 不得超过 15 mm，也不得比初始化退化超过 5% + 0.5 mm。

通过后同一份 `current.json` 提交固定几何、安装参数和骨架模型；骨架进程轮询加载，MANO 在两者版本不同期间等待同步。恢复上一版本也切换同一份记录，失败候选仅保留诊断。几何在实时追踪期间固定。

## GPU 标定方法

网页默认 `parameters`（个体参数）；`delta` 在已有 IK 上学习残差。统一入口是
`moxian_web.mano_calibration.fit_capture(..., method='parameters'|'delta'|'flashsac')`。
三个方法分别可从 `mano_calibrate_parameters.py`、`mano_calibrate_delta.py`、
`mano_calibrate_flashsac.py` 导入调用。
旧的 `mano_fit.fit_capture` 保留为 CPU／混合路径对照，不能与新 GPU 验收数字混用。

两版共享 89 个几何与安装参数、按动作归一化的损失、训练／完整第三轮隔离。
参数 Adam 学习率为 0.01；Delta 网络训练学习率为 0.001。
Delta 网络为 128–128 SiLU MLP，零初始化输出头，初始严格保留已有 IK；输入仅含
同期 IK、EMF、传感器误差、触觉及有效性。动作名称、轮次及预期触点不进入网络。
归一化统计只用训练分区；几何辨识后冻结，再训练残差，不使用逐帧可训练姿态代替网络推理。

GPU 路径使用编译的 FP32 MANO/FK、原始表面三角面距离、有界 Adam、矩阵自由分块 LM。
Warp 查询每个样本的原始顶点与面心，闭合解剖分段仅用于判定符号；人工封口不提供距离。
训练残差使用固定容量的近表面见证，溢出明确拒绝；最终最大穿透始终从完整查询得到。
同一 GPU 姿态算法用于完整留出回放和应用后的实时姿态；变化率投影按时间戳顺序执行，断流重置。
原始上游 SDK IK 仍作为种子和诊断；骨架显示可读取与 MANO 同帧的 `shared_skeleton_pose`。

MJWarp 额外执行独立的分段凸包检查，不对其接触求解器反传。凸包深度只作诊断，
不能覆盖原始 MANO 三角面上的精度或 2 mm 验收。MJWarp 缓冲溢出会中止验收。

首次运行在独立进度中报告编译；服务有匹配保存记录时后台预热。预处理只重算缺失／过期骨架，
缓存键包含原始记录、配置内容、手侧及运行时版本，文件还校验 SHA-256。
候选分别保存在 `methods/parameters/` 与 `methods/delta/`；应用和回退仍通过同一共享模型提交。

60 秒是完整预处理、优化、全部留出验收及交叉检查的目标，首次编译单列。
报告区分总耗时、编译、各阶段、缓存命中、PyTorch 分配峰值及整卡显存采样峰值。
整卡峰值包含 Warp 和同时运行的实时显示。精度或性能不通过均保留原模型。

完整记录的非发布基准：

```bash
.venv-contact/bin/python scripts/benchmark_moxian_gpu_calibration.py \
  --device-home output/moxian/hand_model/348640923d9e2f3f \
  --output output/moxian/debug/gpu-benchmark \
  --methods parameters delta --runs 3 --cache both
```

该命令不写 `current.json`，每个方法分别跑三次无预处理缓存和三次有缓存的完整流程。
`--smoke-steps` 仅用于接线检查，其结果不属于正式性能或精度验收。

## FlashSAC buffer 独立实验

`moxian_web.mano_calibrate_flashsac.fit_capture(...)` 或统一入口的
`method='flashsac'` 使用独立的 GPU 常驻训练 buffer 和编译更新循环。网页标记为
“FlashSAC buffer 实验（直接损失）”，默认方法仍是 `parameters`。候选独立保存在
`methods/flashsac/`，不覆盖其他方法的候选。

依据用户选择，只提取 [FlashSAC](https://github.com/Holiday-Robot/FlashSAC) 的设备 buffer
与编译更新组织，**没有实现或宣称 SAC 算法**：没有 rollout、reward、Q 网络或 Bellman
目标，直接对真实 EMF、固定材料接触点、法向、原始曲面防穿透和几何先验反传。
MANO 几何/旋转/距离均为 FP32，不套用原框架的半精度设置。源码版本及许可记录在
`licenses/FlashSAC-SOURCE.json`、`licenses/FlashSAC-LICENSE`。

该实验采用完整训练 buffer 重放（按动作归一化），每块最多八次 Adam 更新后再读取
GPU 损失/梯度有限性，并刷新碰撞见证。Adam 的动量、方差与步数常驻 GPU，
避免编译图绑定短生命周期的优化器对象。其更新已与标准 PyTorch Adam 对照。
forward、backward、Adam、限位投影由
`torch.compile` 编译，autograd/optimizer 边界仍可能分图；并非宣称单张 CUDA Graph。
它为三个阶段分别保留时间，先拟合形状，再冻结形状辨识几何，最后对指精修。
第三轮和末尾复测不进入 buffer、早停或可辨识性诊断，运行时仍按序列执行历史约束。

此入口是可测的加速实验，不保证更快或更准；沿用全部原始验收阈值，失败不会应用。
独立非发布对照命令：

```bash
.venv-contact/bin/python scripts/benchmark_moxian_gpu_calibration.py \
  --device-home output/moxian/hand_model/348640923d9e2f3f \
  --output output/moxian/debug/flash-replay-benchmark \
  --methods flashsac --runs 3 --cache both
```

## 网页对比训练结果

MANO 面板的“已训练权重”只展示两项：`xMimic 思路版` 和 `FlashSAC buffer 版`。
每项取同一设备、手侧的最近一次完整训练结果；不展示 Delta、重复轮次或中断实验。
这里的 xMimic 名称指现有个体参数实现借鉴其 GPU buffer／编译组织，不代表运行其强化学习框架。

选择后点击“预览此权重”，可在同一实时输入下切换整套几何、安装参数和 GPU 姿态修正。
“返回当前模型”恢复切换前的模型。预览不会写入 `current.json`、修改原始记录或改变验收结论；
未达标结果明确标为“未通过验收，仅供对比”，不能由此直接发布应用。
标定指纹、上游 IK、MANO 权重、手侧和触觉 SID 映射不一致的模型不能预览。

默认关闭 MANO 预测热图，保持网格底色稳定。右栏实际触觉点阵中的有效接触 SID
以亮黄色小球显示在对应 MANO 材料点上，随网格一起运动；无效／未知触觉不显示接触球。
可选预测热图使用平滑的暖色，短暂预测间断时保持上一帧，避免蓝红交替闪烁。

## v13：固定前向、EMA 与标准手型保护（替代在线修正）

按最新要求，网页默认模型和两个对比模型均关闭 MANO 在线 Adam／LM 与触觉姿态修正。
已有手套姿态由固定的坐标绑定、骨架与 MANO 蒙皮做前向显示；触觉只改变黄色标记。
设备采集与上游姿态测量继续运行，不在线学习手型或改写权重。

`parameters` 与 `flashsac` 的训练也改为同一固定前向：89 个共享参数，不再优化逐帧关节角。
更新过程保持阶段顺序，第一阶段辨识 betas，随后冻结 betas 辨识额外几何、安装与对齐。
每阶段保存衰减率 0.95 的共享参数 EMA，最终验证和导出使用该 EMA；不在显示时更新 EMA。

旧候选的附加厚度缩放全部触及 0.625，下限过宽；多个长度／宽度也触及旧边界，原几何先验
代价仅约 0.02，无法约束接触等大损失。此次限制长度微调约 15%、宽厚约 10%、指根 2 mm、
轴倾斜 5°，betas 总范数 ≤1.5，并增加标准 MANO 的顶点位移、边长应变和三个指节的宽厚先验。
`beta_kl_to_unit_gaussian` 是等协方差高斯形状先验的 KL（0.5‖beta‖²），不是 SAC/PPO 策略 KL。
EMA 能减少更新抖动，本身不能阻止持续变薄，因此保留独立几何验收：各指节截面尺寸相对
未修改 MANO 不低于 80%、不高于 125%，边长比也必须在允许范围。所有既有精度验收保持。

`static/calibration-contact-targets.json` 为采集、训练、验证和动作图共用的目标定义。
四组对指都指定 `thumb_distal ↔ 对应手指_distal`，以实际响应 SID 的固定面片／重心坐标
计算材料接触中心；这不是精确世界坐标触点。只有轻触期、双侧触觉有效且同期 ≤25 ms
才施加等式。四组接触分别归一化，避免较长组或重复帧改变组间权重。
活动范围、对掌扫动没有唯一目标接触；并拢是相邻四指侧面的几何先验，不能冒充触觉证据。

网页增加始终可展开的“训练期望接触区域”总览。所有对指阶段均高亮两个目标指腹，轻触期
显示实心黄色，其他阶段用虚线边界表示目标区域而不要求接触；并拢图高亮相邻侧面。
原始数据和旧候选保留，新版本独立训练、完整留出验证，未通过则只可诊断预览。
