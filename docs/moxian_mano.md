# 墨现手套 MANO 自接触标定

在 http://127.0.0.1:8890 的 01 选择 **MANO 手部模型**。使用本机已有左手权重，
Three.js 在本地渲染 778 顶点／1538 三角面，独立 CUDA worker 计算跟踪与自碰撞检查。
已有官方 Skeleton IK 标定和触觉去皮不受 MANO 标定影响。

## EMF 安装关系与平摊参考

EMF 原点、末节骨骼关节、MANO 指尖表面是三个不同的位置。新跟踪路径 `emf_mount_ik_v6` 直接使用原始有效 EMF 6DoF，并计算：

`p_emf = p_distal + R_distal · t_distal_emf`，`R_emf = R_distal · R_distal_emf`。

曲面指尖由 MANO 蒙皮单独产生，不作为传感器原点约束。新记录独立存储 `sensor_joint_position`（5×3 米）和 `mount_rot`（5×SO(3)），表示末节骨骼到 EMF 的固定 SE(3) 变换，通过 `/api/state.hand_model.sensor_mounting.distal_to_emf_position_m` 输出。旧 `mount_pos` 只保留作兼容参数。改变曲面指尖延伸时，固定的 EMF 安装位置不会随曲面移动；这两组变量不能共用一个末端点。

“校正平摊参考”要求佩戴、四指平摊并稳定约一秒。它只初始化原始 EMF 到 MANO 腕部的刚性配准、四指张合角及传感器方向偏移，不修改基础手型、指长或厚度。位置初始化为沿末节方向位于指尖后方 8 mm 的**先验**；这不是佩戴者的测量值，界面明确显示“安装位置为先验”。不能用一次平摊同时确定指长和安装位置。任意没有方向或接触约束的末端位置匹配，都可能通过弯曲指节错误补偿尺寸／坐标差。

建立参考后，位姿输出采用 `mano_wrist_local`，原始传感器通过保存的 `emf_to_mano_rotation/translation_m` 映射进该坐标系；它与官方 Skeleton 的 `wrist_local` 原点不是直接等同的。01 的匹配检查显示 EMF 原点及安装残差连线，连线从预测传感器位置出发，不能从曲面指尖出发暗示两者必须重合。实际原始输入另存于 `input_sensors`。

真实安装位置／方向由独立多动作采集中的共享 5×SE(3) 参数估计，根关节、钩指、握拳、对指提供不同姿态；每指方向变化不足 15° 时拒绝辨识。位置拟合限制传感器沿末节位于指尖后方、且在末节关节的远端，横向安装偏移不超过 15 mm。手指纵向 ±3%、曲面指尖延伸 ±2 mm、厚度 ±2 mm 仍是独立的尺寸变量。接触起始与低载荷约束用于区分“曲面在传感器前延伸多少”和“传感器安装在哪里”；仅有传感器位姿不能唯一恢复末端软组织长度。未改善留出误差或穿透检查失败，禁止应用候选，继续显示先验状态。

2026-11-04 已保存用户明确确认的佩戴平摊片段，参考文件独立保存在设备目录 `sensor-reference.json`，上一版为 `sensor-reference.previous.json`；官方 IK、触觉去皮和十动作原始采集不覆盖。平摊方向与尺寸不匹配时优先保持正常关节和方向，保留传感器位置残差，不以指节翻折强行贴合。

## 模型含义与优化变量

目标是**戴手套的有效外表面**，不声称恢复了裸手皮肤形态。
默认手型先参考已标定骨架；基础尺寸只在“应用候选”时保存；实时接触只显示绿色点，不变形、不施力。

骨长不等于手指外表面长度。骨架多帧关节距离的中位数只作为尺寸信息。`wrist-target-v4` 使用每指总长度初始化平滑的纵向比例（安全范围 0.8–1.3），保留 MANO 本身的指节比例；不会将每个 SDK 骨段长度强制写入曲面。之后只做 ±3% 微调：

| 变量 | 数量 | 更新方式与范围 |
| --- | --- | --- |
| 每帧局部关节 axis-angle | 15×3 存储 | 实时有界 IK＋投影梯度；离线 Adam；PIP／DIP 为屈伸铰链，MCP／拇指基部保留有界侧摆和有限轴向转动 |
| 共享传感器安装位置／方向 | 5×(3+3) | Adam，跨动作共享；位置限制 ±25 mm |
| 每帧手掌整体朝向 | 3 | Adam；以 SDK 骨架和指尖集合初始化，腕部位置固定 |
| 原始 EMF 到 MANO 腕部刚性配准 | 6 | 由明确确认的平摊初始化，多动作拟合只做受正则约束的共享修正；不使用最终重定向目标代替原始 EMF |
| 五指纵向比例 | 5 | 有界 Powell，骨架基准的 0.97–1.03，1% 正则尺度 |
| 指尖软组织延伸修正 | 5 | 有界 Powell，±2 mm，独立于关节间长度 |
| 指段和掌心的横向半厚度修正 | 最多 20 | 有界 Powell，±2 mm；只有已核对 patch 参与，其余保留先验 |
| MANO betas／整体缩放 | 10+1 | 本轮固定，避免间接大幅改变长度 |
| 杨氏模量／有效软层厚度 | 2 | 手动材料先验，不与触觉增益联合反求 |

参数保存布局为 41 项：`betas[0:10]`、整体 log scale `[10]`、五指 log length `[11:16]`、
指尖延伸（米）`[16:21]`、20 区横向半厚度（米）`[21:41]`。
这属于 MANO 扩展，仅保存 betas 不能复现此模型。

Adam 与 Powell 交替执行，尺寸搜索默认最多 160 次评价、180 秒预算；保留最佳有限候选。
目标包含定位残差、低载荷接触间隙、非接触穿透、相对触觉变化及形状先验。
每个尺寸候选重建对应的 MuJoCo Warp 碰撞结构，不能用旧碰撞体评价新尺寸。
留出集只拟合自身姿态，不再优化共享安装参数。

## 操作流程

1. 戴好左手手套，完成官方骨架标定，在无外部接触时完成触觉去皮。
2. 选择 MANO 视图；未完成独立手型标定时显示“默认手型”。
3. 先点击“校正平摊参考”，再点击“开始十动作标定”，按提示完成：张开、并拢、根关节 90°、钩指、虚握拳、
   四组对指、再次张开。每组必须由佩戴者确认，不会自动代替确认动作。
4. 普通动作至少保持 1.5 秒，窗口位置标准差不超过 2 mm、姿态变化不超过 5°。
   对指动作缓慢完成两次“轻触—稍加压—释放”，至少 6 秒；界面显示释放次数。
5. 对指采集前，先在 02 切换触觉矩阵核对对应指腹分区；确认后点击“确认当前接触分区”。
   位置不符时先修正 SID 分配。未经核对的区域不作为确定的尺寸约束。
6. 可在矩阵选择 SID，点击“绑定 SID 到模型点”，再在 01 曲面点选位置；必须位于同一解剖 patch。
   初始 SID 曲面插值只是示意，不能据此宣称精确传感器位置。
7. 十组完成后点击“拟合尺寸”，查看留出定位误差、接触间隙和非接触穿透。
   可预览候选；仅在留出评分改善且非接触穿透不超过 2 mm 时允许应用。
8. 取消或断连会保留已完成组，可恢复采集；当前未完成组需重做。
   “恢复上一版本”恢复上一个已应用模型及其材料／安装参数。

骨架异步输出按时间戳与最近 180 帧原始观测配对，定位／触觉／骨架仍要求相差不超过
25 ms；不会用当前串口帧替代骨架实际对应的旧帧。短暂缺帧（250 ms–2 s）会自动重新
取得当前动作的连续稳定段，保留当前确认和已完成组；超过 2 秒则要求重试当前动作。
服务恢复后重新确认当前动作即可继续。采集使用原始数据，不使用渲染平滑后的信号。

参考建立前保留旧版 `wrist_target_responsive_ik_v5` 兼容预览；参考建立后使用 `emf_mount_ik_v6`，观测改为原始 EMF 传感器而非指尖曲面。四指加入校正后的传感器方向约束，位置安装偏移未多动作标定前降低位置权重。兼容路径：四指先对当前帧腕部指尖目标做有界最小二乘 IK（以上帧姿态热启动），拇指使用原有联合端点 IK，然后做一次小步无动量投影梯度更新，修正真实 MANO 表面与刚性末端锚点之差。实时不再依靠每帧一小步 Adam 累积追赶；离线尺寸拟合仍为 Adam / Powell。

关节 SO(3) 平滑的最大时间常数从 45 ms 降至 12 ms，并随角速度进一步缩短；手掌方向由 35 ms 降至最大 10 ms。手掌保留已拟合的腕部坐标方向，并跟随 SDK 掌部整体转动；不在每次屈指时重做整手指尖配准，以免把屈指错误解释成手掌转动。只有指尖观测连续稳定至少 120 ms、且当前帧指尖 IK 后至少三指仍残差超过 10 mm 时，才重新检查共享手掌方向；单指误差不触发掌部转动。尺寸改变或中断超过 250 ms 时重新初始化。

主服务和手型 worker 的人为限频由约 30 Hz 提高到最多 60 Hz，实际速率由 GPU／碰撞检查耗时决定。网页按包含请求与渲染耗时的 16.7 ms 周期拉取，始终仅一个请求在途；去掉同一轮的重复 MANO 渲染。进程间继续只保留最新帧，不通过预测未来动作掩盖延迟。碰撞检查仍不施力，接触仍是绿色点及二值分区。

合成测试检查突然屈指／释放和 SDK 指段种子不随动作变化时的跟随，三输出帧内指尖误差应低于 2 mm；带 0.04 mm 定位噪声的静止测试检查顶点步长。该测试不是佩戴者实测端到端延迟或姿态精度。

左右方向从当前左手 MANO 的静息均值校验，避免将手背法向当成掌侧屈曲方向。拇指使用独立的入骨方向和左手参考轴（参考 manotorch 的 canonical thumb basis），不沿用四指掌面轴；CMC／MCP／IP 三段方向做联合有界 IK，避免仅用第一段方向时无法确定对掌转动、由末节代偿。参考实现：https://github.com/lixiny/manotorch/blob/master/manotorch/axislayer.py 。在 `wrist-target-v4` 中，官方骨架只作初始化和弱方向先验，实时目标直接读取官方 C ABI `qh_engine_get_last_target` 的 `tips_local`。手掌整体朝向参与优化，拇指三段联合有界 IK 优先拟合该目标；不再强制限制在可能错误的 SDK 拇指姿态周围 8°。每次优化更新仍投影到解剖关节范围；无法满足观测时报告残差，不通过翻折或顶点拉拽贴合。

01 的骨架和 MANO 都显示同帧空心指尖目标及误差线；“指尖目标（腕部）”与它们共用坐标，另保留“原始指尖（EMF）”。两套坐标不能直接比较。`quality.alignment.tip_errors_mm` 为兼容字段名；在 v6 中表示预测 EMF 原点到原始传感器观测的距离，`error_landmark=emf_sensor_origin`，不表示曲面末端必须匹配 EMF；`skeleton.alignment` 则是官方骨架自身的末端误差。这些都不是人体测量精度。骨架与目标残差大时会直接显示提示，不能视为准确骨骼。

保存的官方配置曾同时启用 `viewer.physics_enabled` 和 `qnbot_sdk.physics_enabled`，因此此前说整条管线没有物理分支是不准确的。现在显示路径用同一个官方库的纯运动学引擎，派生配置显式关闭动力学，并核验 steps/contacts/actuators 为零。官方 SDK 继续管理八动作采集／标定。原始官方标定文件不改写；派生配置保存在 `ik/<serial-hash>/runtime/kinematic-<hash>.yaml`。关闭物理后原骨架残差仍存在，不能将异常全归因于接触排斥。

已有十动作原始记录会在拟合时离线重放经过相同官方引擎，另存带同帧目标的数据，不覆盖原始采集。保存手型记录包含官方标定摘要和观测空间；摘要不匹配时禁止应用。

## 接触融合和压缩

原始触觉检测仍保留在 `/api/state.contact`；02 默认使用手势、几何和双侧触觉的融合结果：
内部仍保留确认／候选／冲突／未知，以支持质量诊断；页面接触分布只显示二值：确认 = 1，其他已就绪区域 = 0。01 的确认接触位置显示固定大小、固定亮度的绿色点；02 全部使用同一种绿色填充或灰色填充，不混用边框、虚线、颜色梯度编码。无触觉、断线或过期仍为未知，不写成 0。触觉原始模式单独保留 ADC。单侧信号只作为内部候选；几何和动作不支持时不能仅凭 ADC 宣布接触。

MuJoCo Warp 的 16 段凸包只生成候选，允许正常连接段相邻。随后用当前 MANO 三角面 BVH
复核距离和法向，查询包括 460 个 SID 表面点和 778 个曲面顶点；初始 SID 插值不会作为唯一的碰撞几何。
穿透符号由五指／掌心六个闭合分区的绕数内外测试确定，虚拟封口仅用于体积分类；只有真实表面上的最近 patch 能获得负间隙，避免开放 patch 的背面或远端 patch 误报数厘米穿透。
表面查询仍是采样复核，不能视为连续三角形相交的完整证明；关节限位也不等价于完整生物力学模型。

默认 `E=30 kPa`、有效软层 `h=3 mm`。采用准静态的 ComFree 风格单边法向近似：
`k_i=E A_i/h`，`1/k_pair=1/k_a+1/k_b`，`F_model=k_pair max(-gap,0)`。
这是材料先验下的模型反力，不是完整 ComFree 动力学，也不是 ADC 测得的牛顿力。
接触面积来自激活 SID 对应曲面面积；同一接触对的跨帧相对响应拟合非负增益，饱和 ADC 不参与。

基础厚度主要由接触起始和低载荷数据约束，较强响应只提供相对加载约束。
实时压缩显示已停用，入口移除，后端拒绝 `compression_display enabled=true`。`deformation.max_m` 恒为 0，碰撞检查前后的顶点与关节不被接触结果修改。ComFree 风格的柔顺性公式仅供离线尺寸评分／报告，不能向实时姿态施力。

MuJoCo Warp 只运行 `kinematics`／`collision`，不执行动力学积分或接触力求解，不将接触排斥反馈到关节。即使曲面有穿透，也保留观测驱动姿态并显示接触位置。MANO 保留解剖曲面和 pose corrective blend shapes，不替换成圆柱。横向厚度沿指轴垂面调整，并在 patch 边界平滑；指尖长度用连续渐变，不使用局部顶点拉拽。

## 运行、数据与接口

```bash
scripts/setup_moxian_mano.sh
systemctl --user restart moxian-web.service
```

默认复用 `.venv-contact`；缺失时安装独立 `.venv-moxian-mano`。
可用 `MOXIAN_MANO_PYTHON` 指定解释器，`MOXIAN_MANO_MODEL` 指定已有获许可的左手权重。
不自动下载或分发 MANO 权重。Three.js 复用厂商包内的 MIT 许可版本。

- `GET /api/state.hand_model`：状态、778 动态顶点（米）、21 个关节、独立时间戳、几何版本、融合结果、材料和拟合质量；兼容路径的 `quality.thumb` 保留骨架方向差；v6 中 `source=raw_emf_sensor`，使用 `sensor_origin_gap_mm` 与 `quality.alignment.orientation_errors_deg`，不在两个不同腕部坐标系之间计算方向误差；`input_targets` 与模型帧同时间戳，`root_rotation` 保存整体朝向。
- `hand_model.contact_binary`：按 20 patch 顺序的 0 / 1，未知为 null；`contact_points` 为确认接触的双方表面位置（米）；`simulation` 明确报告动力学关闭、接触力关闭、碰撞检查开启。指尖匹配目标与误差线仅在勾选“指尖匹配检查”时显示。
- `GET /api/hand_model/model`：静态三角面、SID 面片／重心坐标、分区和版本。
- `POST /api/command`：`mano_capture_start/resume/confirm/retry/cancel`、`mano_fit/fit_cancel`、
  `mano_flat_reference`（当前稳定原始 EMF 约一秒；需要佩戴者明确平摊）、`mano_preview`（`enabled`）、`mano_apply/restore/restart`；旧 `mano_compression_display` 仅接受 `enabled=false`，开启请求返回明确错误。
- 采集确认和重试必须传当前 `request_id`；`mano_verify` 传经人核对的 `patch_ids`。
- `mano_bind_sid`：`sids`、`face`、`barycentric`；`mano_material`：`material` 下的 `young_pa/thickness_m/max_compression_m`。
- 数据目录：`output/moxian/hand_model/<serial-hash>/`。保存采集、候选 JSON/NPZ、当前／上一版本、材料及 SID 绑定。
  文件按左手、序列号、操作者 `local` 和 MANO 权重摘要校验兼容性。
- `geometry_revision=wrist-target-v4` 变更了尺寸语义；旧版本已应用尺寸不会静默重解释。保留原文件和十动作记录，重新拟合即可；无需重做官方 IK 或去皮。
- worker 日志：`output/moxian/hand-model-worker.log`。worker 故障不会接管或阻塞串口。
- JSONL 增加原始 6DoF、拟合输入与参数、MANO 输出；首个有效模型及版本变化时记录静态拓扑。
  04 可载入不超过 100 MB 的 JSONL 回放；回放期间禁止设备控制，返回实时后恢复。

测试覆盖协议、时间／坐标、双侧柔顺性、相对增益、融合冲突、采集确认与两轮接触释放，
