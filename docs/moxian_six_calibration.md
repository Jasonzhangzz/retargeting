# Moxian 六动作骨长与 EMF 外参拟合

默认方法 `moxian_wuji`，版本 `moxian_wuji_six_v3_bounded_stable`。**模型属于Moxian**：
使用Qnbot原生25自由度，另在食指到小指MCP处各增加一个轴向旋转角，共29自由度；原始SKN模板和蒙皮权重保持不变。此前Wuji内置人手的21自由度模型
及显示适配已撤回；两套 `wujihand/wujihand2` 结果只保留诊断，不能再预览或应用。

Wuji只提供六动作流程、原生角度范围和已固定版本的原生NLopt `LD_LBFGS`；
`ftol_rel=1e-10`、`maxeval=20000`。FK、接触曲面及辅助姿态属于Moxian，
不将这套目标函数宣称为Wuji内置21自由度 objective 的逐值复制。

## 采集与变量

四组对指、四指根弯曲且指节伸直、平掌；自动切换，完成后停止并等待点击拟合。
此前新采的六动作原始观测继续有效，不需要重采。保持1秒、采集1秒、20帧稳定窗口及
原生姿态范围保留。Moxian RX安装方向只在姿态判别时按八动作参考变换到Wuji判别坐标；
**拟合与实时IK始终使用原始RX观测**。

共51个共享变量：15个独立骨长、五个RX外参30维、TX→腕部外参6维。
另有六组29维辅助关节角，共225维联合向量。沿用原Moxian骨长/外参方法的有界增量：
骨长log±0.15，RX平移±20mm/旋转±0.3rad，全局平移±20mm/旋转±0.2rad。
掌骨、指根、宽厚、关节轴、SID材料坐标和skin weights固定，自由顶点残差为零。
骨长只确定性改变纵向皮肤和绑定，不引入新的mesh优化变量。

## 目标函数与坐标

由不可变的Moxian八动作初始化估计 `T_wrist_TX` 和 `T_distal_RX` 初值，
不继承错误Wuji显示模型的骨长、旋转、角度或形变。

```
预测RX位姿(TX) = inverse(T_wrist_TX) * FK_Moxian25(q,L) * T_distal_RX
目标 = EMF位置/旋转误差 + 指腹接触位置/法向
     + 平掌伸直/共面 + 四指桌面姿态参考
     + 骨长/比例/外参先验 + 弱姿态零空间先验
```

旋转误差比较的是 **Moxian末节骨旋转 × RX安装旋转** 与
**TX→腕部旋转 × 原始RX旋转**。不能把骨轴、Wuji骨架显示坐标或皮肤基当作RX坐标。
长度与平移存米，旋转为矩阵，角度为弧度。初始化、拟合、CPU IK和mesh共享同一模型。

优化只在六组静态代表观测上计算；噪声仅从各新采集片段估计。接触材料点拟合前冻结。
界面记录真实评估次数、目标值与梯度，不运行姿态网络。

## 应用检查与实时

拟合后单独用原始EMF驱动Moxian有界QP回放六个观测，动作目标不参与实时IK。
位置RMS须≤15mm且不较原Moxian基线退化超过5%+0.5mm；旋转平均≤15°、
不得较基线退化超过2°、任一接收器误差不得超过35°。原生L-BFGS须正常收敛。
不满足则保存报告并保留原模型。该检查是采集姿态回放，**不是独立真人复测或完整穿透验收**。

只通过上述检查的候选自动应用，骨骼和mesh仍由同一个原子活动模型指针与时间戳约束。
实时是Moxian25＋4轴向旋转的有界QP及原Qnbot LBS，不调用Wuji内置人手IK。

## 实现与复现

- `moxian_web/moxian_six_calibration.py`：六动作输入、Moxian目标和真实原生L-BFGS。
- `bone_extrinsics.py`、`emf_qp.py`、`qnbot_surface.py`：51维模型、实时IK与骨长蒙皮。
- `wuji_gesture_frame.py`、`wuji_native_capture.py`：仅用于六动作静态采集。

```bash
.venv-contact/bin/python scripts/calibrate_qnbot_glove.py \
  --capture output/moxian/hand_model/<设备hash>/qnbot/wuji-calibration-capture.json \
  --output output/moxian/debug/moxian-six
```

结果使用独立目录 `qnbot/methods/moxian_wuji/`；旧17动作、六动作原始数据和错误Wuji
候选都保留。此前v1六动作的离线回放报告见
`output/reports/wuji_native_full_calibration_20261112/moxian_six/report.json`：位置RMS约1.89mm，
平均RX旋转约9.12°（最大约25.78°），对比被撤回Wuji模型回放平均约62.85°。
这些是固定采集姿态的检查，不代表全运动范围误差。

## 末节反折与指根轴向旋转（v2 历史）

v2将四指DIP下限定义为物理伸直角减30°，而不是原始关节角减30°。
原始模型含约9°–16°固定弯曲，旧raw下限−10°甚至会使部分手指无法伸直。
共同限位由 `finger_limits.py` 提供；初始化SLSQP、离线辅助姿态和在线QP共享该范围。
旧初始化缓存按IK版本失效。PIP、拇指和原生各轴方向不因本项调整。

新增指根轴向旋转放在MCP外展/屈伸之后，轴取原生proximal→PIP方向；
旋转作用于整指的FK、接收器、蒙皮与触觉材料点。原生25个轴与蒙皮权重不修改。
四个旋转角是逐姿态/逐帧的自由度，不增加51个共享几何/安装参数。

根据用户选择，取消±5°的小范围硬门槛。离线角度使用覆盖一整圈的[-π,π]数值区间；
在线角度随历史连续展开，可跨过±180°，不会在该数值边界卡住或跳转。
旋转由原始EMF位置/方向残差驱动，保持速度与历史约束，仅有较弱的回正先验。
配置与范围随 `bone_extrinsics.joint_limit_policy` 和 rig 一并保存。

`QnbotSurface(..., finger_twist=True)`启用扩展模型；历史25自由度模型可按其保存的
限位加载与回滚，不会被静默改成29维。模型版本改变后骨骼和mesh仍通过相同hash切换。
旧六动作原始EMF可复用，修改限位/姿态维度后应重新拟合骨长与外参。

当前v2在同一份最新六动作记录上的对照见 `output/reports/moxian_distal_twist_20261112/same_capture_comparison.json`：25自由度旧模型位置RMS约1.10mm、平均旋转约6.46°；加入DIP反折和四指根轴向旋转后约0.70mm、1.88°。这是采集姿态回放，不是独立真人动态复测。


## v3：拇指分支与逐帧稳定性

现行默认边界：指根轴向旋转±30°，DIP相对物理伸直反折20°，PIP与拇指MCP/IP反折10°。
这些是明确的模型默认值，不代表实测个人关节极限。原始模板、宽厚、骨轴和蒙皮权重保持不变；
边界相对固定origin消除后的物理伸直定义，而非原始关节零位。旧候选仍按保存的限位只读查看。

最后平掌动作中，拇指MCP/IP辅助角被限制在物理伸直±5°，另加3°尺度的伸直项。
拇指根部CMC屈伸与MCP侧摆存在近似共轴的补偿方向；离线增加相对平掌端点的20°尺度先验，
在线这两个角的姿态权重8、历史权重80，其他拇指关节保持较弱的姿态项。
平掌拟合得到的四个拇指根部角保存为中性参考；MCP/IP屈伸的中性参考仍是物理伸直。
这只是固定参考姿态，实时目标仍来自原始EMF，不用动作标签驱动或保存修正网络。

QP速度约束现对整个输出帧应用：每个角限制在上一有效输出±v_max×dt，v_max=2π rad/s，
dt最多按1/15秒计算。所有迭代和重试共享这个预算；重试只改变阻尼，不再增加物理速度。
历史项使用上一输出，不再外推两个输出的差值。无效单帧保留上一有效分支；超过250ms断流、
模型切换与回滚清空历史，首次输入仅按几何边界初始化求解。

验证与记录见 `output/reports/moxian_stability_20261112/`；静态六动作回放不能代替真人动态运动检查。


## 源IK分支恢复与标定初值保存（2026-11-16）

源算法为 `moxian_studio_native_qp_v3_calibration_seeds`。模型、29自由度、标定目标和骨长／外参拟合保持原有定义。六动作拟合后，自动从该次标定的训练EMF、拟合姿态和通用初值，用相同完整源IK目标细化每个动作的初值。保存于标定产物的 `source_ik_initialization`，包含关节顺序、采集来源、模型hash和内容校验。该步骤不使用独立验证数据。随后经过JSON序列化／重载，再用线上相同 `StudioQPSkeleton` 回放验证；报告记录初值库校验和与验证版本。重新标定会重新生成，不依赖本次手套的临时文件或进程缓存。

正常热启动保持原有有界QP。只有RX残差超过已有重试阈值且局部下降停滞时才探索，间隔至少8个消费帧；冷启动的大残差也可探索。运行时按当前EMF、相同姿态先验及历史参考的完整成本，逐指挑选保存的初值，组合为一个探索种子，替换原第三个通用种子。其余两个通用种子保留，总探索预算仍为每次三个QP求解。无初值库的旧模型仍可使用三个通用种子，但旧候选不能绕过新标定的保存检查直接应用。

保存姿态仅作为求解起点；动作名称只供审计，不用于运行时识别或输出选择。至少改善5%才选择目的分支。有上一输出时，沿关节空间线段按原 `v_max × dt` 速度盒逐帧过渡；只把实际输出写入历史。跨分支期间RX残差可能暂时增大，通过 `tracking_errors.recovering` 与 `alignment.ik.branch_recovery` 报告。快速运动中仍正常下降的局部解不触发恢复。

显式重置、模型切换和有效输入断流清空动态缓存，静态标定初值保留；非法包不能推进或清空历史。几何 `model_hash` 保持几何语义；独立 `skeleton_runtime_revision` 包含源算法版本、几何hash与初值库校验和，线上与原始EMF离线重建一致。旧骨架录制不能重新贴上新版本标签继续使用，GeoRT模型来源也必须匹配新指纹。

现有标定已使用同一个生成函数从保留的原始六动作记录补齐初值库；本次补齐没有重新拟合骨长和外参。两段旧的无原始EMF骨架录制（6457帧）及其接触缓存、训练指尖副本已删除。标定记录中旧骨架字段清除，原始接收器观测保持逐值一致。旧GeoRT权重保留，但需要以新源数据重新训练才能用于当前输入。
