# MANO 离线训练与收敛曲线

网页地址为 `http://localhost:8890`。从 v20 起，网页训练方法均采用完全混训：连续标定记录中的全部训练帧进入 GPU 常驻 buffer，每次更新同时使用所有动作。当前记录为 2442 个训练帧，另有 1527 个完整留出帧只作验收。无整体手型／非对指／对指阶段切换，无 32 步手指轮换，无动作覆盖抽样或重复帧。网页步数表示整个混训循环的最大更新次数；旧 `batch_size` 调用参数不再缩小连续标定的训练集，报告记录实际全量帧数。

标准 MANO 手型、骨段尺寸、指根、宽厚与安装对齐在同一循环内联合辨识，以 KL 先验、形状参数软先验、形变幅度、厚度和边长的可微惩罚控制自由度。混训不会因解剖形状越界而拒绝或回滚有限更新；厚度下限 0.8、上限 1.25 和边长比 0.65–1.5 转为 softplus 软损失，使用 p=8 聚合避免少数异常边被大量正常边平均稀释，权重 1000，提前作用的比例余量和尺度均为 0.02。最终手型、接触和穿透验收保持原要求，未通过不自动应用。网页损失项可选择“形状软约束”。每条对指样本的几何梯度只进入拇指及对应手指，不能通过该样本改变其他手指或全局 beta；非对指观测继续学习整体手型。安装对齐与观测参与掩码保持原有定义。固定前向仍不使用的六个拇指轴参数明确冻结，不声称因混训而变得可辨识。

EMA 只作用于腕坐标下的非关键静止表面：关键区域直接采用有效更新，其他顶点执行 `V_new = 0.95 * V_previous + 0.05 * V_raw`。关键顶点使用当前 buffer 内对指两指蒙皮权重合计 ≥0.5 的区域并集；四组对指均出现时，五指均可直接更新，掌部等非关键区域平滑。补偿量作为固定 `rest_vertex_residual_m` 保存，无自由逐顶点残差网络，运行时不更新几何或优化姿态。

## 接触指尖与 EMF 朝向

对指轻触且双侧目标区域触觉有效、时间同步的样本增加 `contact_tip_emf_orientation`。通过腕对齐及安装旋转，将 EMF 旋转换算为远端指骨朝向，再比较 MANO 指尖切向。初始权重 40，与接触位置使用相同的按动作归一化规则；每个接触包含双方指尖。接近、释放、未知触觉以及失效 EMF 不强制对齐。原有完整传感器姿态残差继续保留。

## 阅读曲线

- 橙色虚线为优化参数，绿色实线为接受的参数／表面 EMA 结果，约每秒采样，开始和结束额外采样。混训中两条参数曲线可重合：参数直接更新，EMA 只作用于非关键表面。
- 默认展示全量训练 buffer 的混训损失，可选择具体损失项；旧记录保留原有阶段标签，不与新混训曲线连线。
- 紫色 KL 为 `0.5 * ||beta||²`，蓝色 KL 为按 `GEOMETRY_SIGMA` 归一化的几何参数距离。这是等协方差高斯的参数先验诊断，不是 SAC 或策略分布 KL；混训时手型仍可更新，紫线不应被人为固定。
- 同时显示训练接触间隙、EMF RMSE 和指尖—EMF 方向差。缺失测量保留为空，不绘成零。
- 可切换两种方法各自最近一次训练记录。曲线只读取训练分区，不能替代完整留出验收。

`GET /api/hand_model/training_trace?after=0` 返回当前曲线；可加 `method=parameters|flashsac`。后续请求使用响应中的 `cursor` 和 `run_id` 增量读取。每次训练的原始事件另存至设备目录 `training-traces/<run_id>.jsonl`。

接触法向目标在 v16 使用 `contact_normal_cone_v2`：固定 taxel 绑定和触觉权重不变，以原始三角面的面积加权顶点法向作重心插值，再按触觉响应求区域法向。两侧外法向应相反；允许 15° 偏差，超出部分按 15° 的单位弦长归一化。距离仍按 2 mm 归一化，权重仍为位置 320、法向 40。训练角度图新增紫色法向偏差曲线，未知区间留空。报告同时保留原始面片与平滑法向的留出角度；原始三角面距离、法向及穿透验收规则不放宽。最终额外记录三项接触损失对完整共享参数向量的梯度范数，仅作训练诊断（包括被冻结的坐标），不用于模型选择。

MJWarp 凸包交叉检查在独立进程中执行，Torch 数据写入与 Warp 查询使用同一流。超时、进程崩溃或无效查询会记录为失败，保留已训练候选但禁止应用。显示与训练进程内的 Warp 构造／查询使用可重入调度锁，避免同时初始化或捕获计算图时的流状态竞争；损失反传仍使用批量 GPU 计算。

增加步数只在尚未收敛时可能有帮助；扩大数据覆盖也可能引入更难样本，需要看完整留出结果。首次编译独立显示，期间不伪造曲线。优化预算可以超过 60 秒，但不会放宽端到端 60 秒性能验收或接触精度阈值；失败候选不自动应用。

优化器默认仍为 Adam。选择 `MANO＋Delta` 后，网页“优化器”可选 `Muon＋Adam`，或主入口传入 `training_options={'optimizer':'muon'}`。仅两层隐藏层的二维权重矩阵使用 PyTorch Muon（学习率 0.001、动量 0.95、无权重衰减、`match_rms_adamw`）；89 维物理参数保持 Adam 0.01，网络偏置和输出头保持 Adam 0.001，不将物理向量强行改成矩阵。个体参数版、FlashSAC 版不接受 Muon 选择。曲线记录实际优化器，报告保存参数归属；旧请求未指定时继续使用 Adam。切换对下一次拟合生效，不改 EMA、损失、留出分区和验收要求，也不代表已验证收敛或精度更好。

从 v20 起移除 beta 范数和骨段、宽厚、指根参数的硬裁剪；原范围只作为可微 softplus 先验。安装和整体坐标对齐的数值范围保留。几何载入检查有限性及正尺度，不以旧范围拒绝模型。

`delta` 现在使用同一次 Adam 反传，同时更新共享几何和两层 128 单元 SiLU 残差策略，不先冻结几何。无逐帧自由变量。策略零头初始化保持原 IK；动作、轮次、接触标签和未来帧不进入输入。几何观测预测残差使用当前几何，归一化统计仅在初始训练分区计算；采集间断和留出轮次间隙重置变化率损失的时序邻接。关节物理坐标范围约束残差，变化率采用训练软惩罚，运行时不执行额外因果裁剪或优化，因此按单帧或分块推理应一致。策略输入的实测触觉会影响姿态前向预测，但网络和几何权重保持固定。训练、留出回放和网页调用同一姿态修正函数，骨架和网格共用最终关节状态。

网页“继续训练当前 Delta 权重”使用最新联合候选作权重热启动，恢复共享几何、安装参考、固定表面补偿、Delta 网络、原训练集归一化和物理姿态坐标，复用原训练事件生成的冻结模板。主入口可传入 initial_candidate；网页接口传 resume=true 和 resume_run_id，帧顺序、采集哈希、手侧、模型和骨架版本必须一致。最大步数表示本次追加的全 buffer 更新次数，报告另记累计步数与父运行 ID。已有 checkpoint 未包含 Adam 动量，因此续训明确记录 optimizer_state_restored=false，并重新初始化优化器；不能称为逐位等同的中断恢复。独立复测仍只作验收，不参与早停或选择权重。父 checkpoint 单独归档，续训候选不自动替换未通过验收的模型。
