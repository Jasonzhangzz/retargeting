# 历史实现：动态link表面接触与双向拇指（fit v6）

接触位置loss使用指定link指腹区域的当前原始三角面上同一对点，目标严格为0；法向loss使用该处面积加权插值表面法向，目标dot=-1，取消15°损失死区（15°仍是验收容差）。支持顶点—三角面、边—边最近距离以及边—三角面相交；从这些实际曲面候选中按距离320、法向40的相同联合能量选接触证据，防止相交后的任意零距离点掩盖法向问题。材料坐标随当前几何／姿态刷新，再通过所选重心坐标反传；纯几何最小距离独立报告。区域、接触图和taxel绑定保持固定。GPU批量BVH查询使用CUDA Graph；完整Inductor训练编译暂不支持，显式compile会报明原因。

训练碰撞项每步检查混合batch中的最多3个接触帧，采用超出容差的平均平方残差与最大平方残差，各权重160；添加零残差不会稀释惩罚。目标接触对容忍2mm，其他部位容差0，不做硬拒步。原始与EMA后曲线包含同一碰撞项；完整独立复测仍检查所有帧。

保留每指长宽厚15参数，禁止任意顶点变形；可联合小幅Delta，网络仍只读取真实观测。仅选定接触事件施加link接触损失，其余轨迹不吸合。2mm穿透容差属于独立碰撞项，不再作为接触位置目标的死区。

拇指MCP/IP相对物理展平允许负向30°（可配置建模值，并非个人实测值）。扣除URDF固定弯角后设置raw-q下界，避免误把包内负角当作已允许反折。上游SLSQP、模板、GPU Delta／网格共享该范围；左手直零位资源同步更新，原始厂商文件不改写。上游版本指纹变更后，网页拟合前自动从原始EMF回放旧记录，不能只换标签复用受旧限位裁剪的种子。

下文为历史实现记录。

# 当前默认：手指尺寸标定（fit v4）

当前从标准Qnbot手型重新辨识每指长、宽、厚，共15个独立参数；同指各节共享对数尺度，保留骨段比例，掌骨不变。冻结自由顶点残差、指根、关节轴和安装／坐标变换。长宽厚采用二次、四次及宽厚比例软先验，没有形状硬截断；非关键指的尺寸EMA不会生成自由mesh补偿。尺寸LR .001，Delta可选且保持小幅惩罚。旧任意mesh模型仍可比较，不能直接续训成尺寸模型。

EMF位置权重由1提高到320，完整旋转和指尖方向各40。目标接触的切向位置保持对齐，法向间隙以[-2mm,0]为无惩罚带。碰撞查询仅对当前贴合事件指定的骨段接触对容忍2mm压入；其他接触对无该容差。未穿透的正间隙不再有排斥损失。最终仍报告实际原始曲面穿透并保留2mm验收上限。

模板近邻查询排除两个区域共享的关节边界顶点，修复折叠动作在同一个材料点上得到假零间隙。下文为先前自由mesh版实现记录，当前默认训练自由度以上述规则为准。

# Qnbot 官方连续 mesh 与轨迹标定

默认后端为 `qnbot`；`MOXIAN_SURFACE_BACKEND=mano` 或网页“模型基础”可选旧 MANO。官方路径不加载 MANO 权重。资源来自已安装 Dynamic OpenXR 0.3.4 算法包；可用 `MOXIAN_QNBOT_RESOURCES` 指定包含 `resources/` 的目录。左右 SKN 各 11598 顶点、23184 三角面、20 蒙皮骨骼，官方 MJCF 有25关节。它是标准人手模型，不是已证实的手套外表面扫描。

`qnbot_surface.py` 从官方 MJCF 读取关节树／轴，从 SKN 读取原始曲面和绑定权重，PyTorch 做可微 FK／LBS。骨架与静止曲面同时变形，同步更新逆绑定。学习骨长、指根、关节轴、宽厚、安装、坐标配准及直接顶点残差；推理只做固定权重前向。物理参数 Adam LR .01，米制顶点残差 LR .0001，Delta LR .00001；Muon 只处理 Delta 隐藏矩阵。顶点残差不是逐帧自由度，不会在线学习。边长、局部刚性、厚度、位移和平滑项均为软惩罚；没有恢复旧形状硬边界。

`surface_backend=qnbot|mano` 可传给 `mano_calibration.fit_capture`；旧 MANO profile 的显式 ABI 继续路由旧实现。`qnbot_calibration.fit_capture` 和命令行均可独立使用。`parameters` 与 `flashsac` 使用直接标定损失，无 reward／critic；两者复用 GPU replay，`delta` 额外联合训练两层128 SiLU、零输出头的25关节残差网络。动作／分区／目标接触不进入策略特征。输入归一化只读取训练集，时序状态在窗口边界或 >250ms 断流时重置。

## 连续采集 v4

17动作，训练／独立复测各一遍，每动作最少6秒。两次完整“展平→贴合→展平”才结束；6秒不足自动延长，允许暂停、补录和取消。回位使用冻结官方参考与初始展开观测，不使用训练候选。四指弯曲、离掌面容差为初始化95分位基线加8°／12°，拇指返回方向20°；三帧确认、3°滞回用于噪声过滤，不规定保持时长。全手观测可判断回位，非目标手指训练权重依旧为零。

所有原始 EMF、同期触觉与时间戳保留。每帧保存关键 patch 位置、法向、有效性、窗口／循环／阶段和冻结参考指纹。推算轨迹明确标为模型代理，不当作皮肤表面实测真值。仅选定接触帧有位置320、相对法向40；全程保留有效 EMF、指尖朝向和相对展平起点的弱轨迹项（权重0.1，10mm／10°鲁棒尺度）。各动作混训，独立复测不选模板、统计量或早停。

20 patch／460 SID 语义保留，官方 mesh 重新建立固定材料坐标，旧 MANO 面片号不通用。默认映射是解剖学初始化，用户应逐区触碰核对；不是厂商实测 taxel 安装表。MCP 掌面是额外虚拟训练区域，不改变 SID ABI。

## 存储、接口和验收

新记录与候选写入 `output/moxian/hand_model/<设备hash>/qnbot/`；旧根目录 MANO 文件不覆盖。候选绑定官方资源、拓扑、区域、设备、手侧、初始化与原始采集摘要。旧 MANO checkpoint 不能直接续训为25关节模型；旧原始 EMF／官方关节轨迹可以重新预处理，但不能声称已完成 v4 全手展平证明。

`GET /api/hand_model/model` 返回按版本缓存的拓扑；`GET /api/hand_model/mesh?sequence=N` 返回最近8帧中的指定帧；`?after=N` 对未变化的最新帧返回204。二进制为小端：0–3 `QNB1`，4版本u32=1，8序号u32，12顶点数u32，16关节点数u32，20保留u32，24时间戳f64，32起32字节几何版本，64起64字节绑定版本，128起连续float32顶点XYZ，再关节点XYZ。网页核对版本与序号，防止切换权重时混用拓扑。`/api/state?view=mano` 不嵌入顶点JSON；服务器原始录制仍保存同帧完整几何。

防穿透使用原始曲面顶点／三角面重心对闭合解剖分区的 Warp 查询，封口只参与内外分类，不提供接触距离；不以 MuJoCo 碰撞代理验收。完整留出检查未在预算内完成时明确失败，保留原模型。接触均值≤3mm、最大≤5mm、穿透≤2mm，保留EMF及松开防吸合检查。失败候选可显式比较，不自动应用。

无缓存离线调用（不会发布模型）：

```bash
.venv-contact/bin/python scripts/calibrate_qnbot_glove.py \
  --capture output/moxian/hand_model/<设备hash>/motion-capture.json \
  --serial <序列号> --side right --method delta --steps 480 --seconds 45 \
  --output output/moxian/debug/qnbot-native-delta
```

当前版本不假称原生 mesh 必然更快：顶点数约为MANO的15倍，buffer只常驻观测／patch参考，完整曲面按批展开，逐帧原始曲面验收可能成为耗时瓶颈。曲线仅展示真实更新；Qnbot无MANO β，原KL画布显示几何软先验与mesh边长项，不伪造策略KL。

EMF 完整朝向和指尖方向全程各权重40。Delta 实际修正／原始输出分别以3°为尺度软惩罚（320／80），不设置3°硬截断；网页显示朝向误差、Delta RMS／最大角度和梯度。非关键区域 EMA 直接约束实际静止曲面位移，包括骨架变化引起的耦合位移。主学习对象是共享mesh，Delta只是姿态补偿。

固定前向在服务启动时预热 CUDA Graph。完整训练编译通过离线 `--compile` 显式启用并单独计时；默认交互训练不等待首次 Inductor 编译。FlashSAC 模式用 GPU 有放回随机片段采样，仍直接优化可微标定损失。原始三角面验收用每个world独立BVH与批量CUDA Graph，检查所有顶点和三角面重心，不能当作严格连续三角形相交证明。现有778顶点MANO接触预测网络不适用于官方拓扑，因此官方后端仅显示实测触觉，不复用该网络。

零输出严格保留上游IK：部分历史SDK角度超出打包MJCF限位，Delta可向合法区间回退，但不允许把已有越界进一步放大；不会把限位投影误算为学习到的角度修正。训练曲线与候选均按后端独立存储，原MANO曲线不覆盖。
