# Shadow 到 MANO 的固定接触映射

入口为 `scripts/inspect_shadow_mano_mapping.py`。模型、模板和接触映射带来源指纹；原始 Shadow 数据的逐样本接触标签缺失时，源点明确标记为抓型模板标注的姿态重放。

中性姿态按同名手指/指节建立解剖坐标，按骨长转移目标点和法向；仅在对应 MANO 蒙皮权重区域内选择三角面并保存重心坐标。姿态改变后仍由同一面和重心坐标重建模板点，不跨手指重新分配。

当前 CEM 在该固定模板点周围构建同解剖区域的手面 patch；物体模板目标来自原 Shadow 标注在实际网格上的一次投影。优化和验收规则见 [MANO求解](mano_solver.md)。映射诊断与抓取稳定性分别报告，不能把模板标注当作数据集接触真值。

映射用于初始化和当前方法输入，不提供独立抓取 solver。私有 MANO 权重由用户另行提供，不随代码分发。
