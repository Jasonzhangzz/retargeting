# 手指交叉原因核对

确认存在实体 Wuji 手指间的网格相交，不能全部解释为 MANO 叠加显示。此次没有修改控制器或重新运行抓取，仅检查已有输入、执行状态和碰撞配置。

## 原因

1. `retarget/mano_noise.py:retarget_from_mano` 逐根手指做骨链方向 IK，仅有各关节限位，没有跨手指距离或自碰撞约束。各指单独拟合正确不代表合起来无交叉；输入的错误 MANO 还会持续提供交叉方向目标。当前生成的参考和第一帧状态就可能自交。
2. 默认 ComFree 使用 `sugar_box_sdf.xml` 及 `assets/wuji/right.xml`：手部 mesh 的碰撞位均为零；手部 querypoint 的 `contype=1, conaffinity=4`，不会形成手指—手指碰撞对。默认物理 rollout/执行缺少手指间的碰撞响应。`--executor mujoco` 使用另一份 mesh 场景，不能把这两个执行模型混为一谈。
3. objective 确实包含 `_finger_joint_collision_loss`，没有被 ADMM 分支漏掉。它将各 link 的 query-point 云拟合为胶囊，对不同手指的间距平方不足量加罚，当前权重 100、表面 margin 2 mm。胶囊半径使用径向范围的 90% 分位，属于几何近似。这个 soft cost 可与接触/物体目标交易，没有自交候选硬剔除；默认一次 AdamW 更新也不会保证跨过已自交初态的可行性。
4. ADMM 的物体表面点更新不负责手指—手指可行性。物体接触点局部可行并不等于整只手无自碰撞。

## 已有轨迹中的证据

- 零扰动直接 IK 参考：中指/无名指末节的最小胶囊表面间距约 -7.47 mm；执行初态同样自交。
- 全手 0.35 rad、ADMM：361 个保存状态全部存在超过 1 mm 的胶囊重叠；最严重为第 154 个执行状态（1.54 s），中指与无名指的 link3，胶囊负间距约 15.32 mm，独立 MuJoCo 凸包距离为 -14.45 mm。
- 对该帧原始渲染三角面另做边—三角形相交检测，确认中指表面边严格穿过无名指三角面内部。相交点约为 `[0.477669, 0.331367, 0.233292]` m。因此不是仅有胶囊近似误报。
- STL 网格不是封闭流形，因此未把 winding-number 检查的所谓内部深度作为精确穿透深度；14.45 mm 是凸包模型的负间距，不是精确 STL 穿透深度。

[胶囊/凸包检查数据](results.json) · [三角面交叉证据](triangle_mesh_witness.json)。可用 `python reports/finger_crossing_audit/audit.py` 和 `python reports/finger_crossing_audit/check_triangles.py` 重复检查。

## 对先前成功率的影响

此前 9/9 是“物体被抬起并保持离桌”的事件通过率，没有把手部自碰撞作为无效条件。不能将它解释为 9/9 个物理有效抓取。这次检查已明确发现其中存在穿指状态。

修复应在纯 MANO 重定向中加入多指联合几何避碰、保证初态可行，并在 hand action 更新/输出时检查或约束跨指距离。执行器也应具有一致的手指间碰撞响应。此类机器人自身几何约束不需要读取原始可行抓取模板；仅加大软惩罚或仅增加 ADMM 轮数不能保证不交叉。
