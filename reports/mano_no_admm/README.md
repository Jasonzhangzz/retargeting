# 同一噪声输入：完全关闭 ADMM 的补充对照

历史协议：本报告保留旧的差分参考输入和结果。当前 `--noise` 已更改为直接 MANO 重定向、首帧即施加扰动；新结果与耗时见[直接参考测试](../mano_direct_reference/README.md)。

输入先验核对：本实验保留了原手腕轨迹、接触时序/手部语义对应，并以原可行 Wuji 参考做差分扰动。9/9 不能解释为无可行先验的自主抓取恢复；objective 确实接收扰动后的物体坐标和手指参考，详见[输入审计](../noise_input_audit/README.md)。

9 组扰动 MANO 经 SDF 投影得到的错误模板，在完全关闭 ADMM 后均能求出完成抬升和整段原轨迹的 hand action。

此处与上一轮“固定模板但保留 ADMM”的对照不同：本次使用 `--adamw --no-admm`，关闭表面搜索、一致性惩罚、对偶更新及跨窗口接触记忆。保留同样的物体位姿/速度、实际物理接触 wrench 等 hand 目标；每窗口一次 hand 更新、8 初值、seed=0、3.6 s 闭环。实际执行使用 ComFree，输入直接复用上一轮保存的文件，没有重新生成或更换扰动。

逐个运行检查 `contacts.npz`：`c == template`，`dual == 0`；audit 中 ADMM 与探索均关闭。因而这些结果确实来自固定错误模板上的 hand-only AdamW。

| 方法 | 完成抬升与运动 | 严格起升同步验收 |
|---|---:|---:|
| ADMM + 采样 LM | 9/9 | 8/9 |
| 固定模板，保留一致性/dual | 9/9 | 9/9 |
| 完全关闭 ADMM | 9/9 | 7/9 |

沿用上一轮运动标准：位置 RMSE 与运动终点位置误差均 ≤20 mm，姿态 RMSE 与终点姿态误差均 ≤15°，终点中心抬升 ≥50 mm。严格同步还要求：参考离桌 5 mm 的运动采样中，实际物体至少 95% 也离桌 5 mm。未达到严格同步的是 all_350 与 index_600，分别有 80 ms 和 100 ms 的起升延迟，之后均完成操作。

强扰动 all_600 的模板相对零扰动投影最大偏移 41.6 mm；完全无 ADMM 时终点抬升 168.9 mm，位置 RMSE 6.76 mm，运动终点误差 2.62 mm。

结论限定为该 sugar box 示例、该种子和这九种扰动，不能外推任意错误模板。模板是优化中的软引导，实际执行接触由手部几何及动力学决定；本实验表明这里仅优化 hand action 已足够完成补偿，没有得到 ADMM 提高操作完成率的证据。严格起升时序及终点保持也应与操作是否完成分别看待。
