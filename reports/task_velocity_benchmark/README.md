# 任务 wrench 修正与物体速度目标

## 已完成的行为

- 当前接触组合不能实现任务目标时，优先改善任务残差。几何正则只用于可行候选之间的选择，不再挡住任务修正。可行组合仍跳过搜索。
- QP 使用有界切向任务梯度步和回退；LM 的摩擦锥投影允许随切向负载增加法向挤压力，避免只削减切向力而无法建立必要预载。
- 物体目标包含世界坐标系线速度和角速度，跟踪同一 MANO 位姿插值的导数。终点、暂停及参考截断后，目标速度为零。FA/AdamW 的原生解析伴随和 SQP 的符号目标都接入了新项。
- 默认仍为每窗口一轮、一次 hand 更新；没有通过增加 hand 更新预算获得下面的结果。

默认配置：

```yaml
loss:
  obj_vel: 0.1
  obj_ang_vel: 0.03
```

这两个系数乘在速度残差上再平方。结合原来的 `obj_pos: 1.0`、`obj_rot: 0.3`，它们相当于 0.1 s 的速度尺度；`reference_pose_scale` 和终端权重继续作用。旧配置缺省时也启用；显式设为 0 可关闭。每步目标速度保存为 `rollout.npz/object_reference_velocity_world`（执行步数 × 6）。角速度先从物体局部坐标转换到世界坐标再比较，梯度同时包含速度和四元数方向的影响。

## 任务修复验证

`tests/test_contact_task_wrench.py` 使用受控的侧面接触：原组合中接触点共线，无法产生任务所需的绕该线力矩。独立非负摩擦边 LP 验证原组合不能实现该任务，并验证 4 mm 内存在满足约束的解；力上限也纳入证书。

默认 8 组、每组 3 步 LM，在 CPU 和实际 CUDA 上分别运行同一生产实现，均得到：

| 检查 | 等效运动误差 | 移动 | 结果 |
| --- | ---: | ---: | --- |
| 原组合 | 0.17335 mm | 0 | 不可行，搜索 |
| 修正组合 | 0.08541 mm | 2 mm | 达到 0.1 mm 容差；独立 LP 也验证修正后的组合能实现任务 wrench |
| 下一次检查 | 0.08541 mm | 不再移动 | 保持可行组合，跳过搜索 |

QP 测试也验证了：当前组合任务不可行、邻域有可行证书时，接触更新能降低 wrench 残差并达到容差，即使几何总代价暂时上升。记录见 [task_repair.json](task_repair.json)。这些是受控求解器测试，不是任意 MANO 模板扰动的闭环成功率统计。修复受 5 mm 半径、表面 patch、力约束及有限求解预算限制。

## 速度目标的独立对照

从同一历史运行 2.37 s 的状态、速度、warm controls、接触点和 dual 重启，冻结第 71 帧参考并继续 1.2 s。两组使用相同的新接触更新器，只切换速度权重。所有静止参考的目标速度均验证为零。

| 指标 | 速度权重为 0 | 默认速度权重 |
| --- | ---: | ---: |
| 物体线速度 RMS | 0.06361 m/s | 0.05177 m/s |
| 物体角速度 RMS | 0.17078 rad/s | 0.15716 rad/s |
| 最后位置误差 | 15.45 mm | 14.46 mm |
| 最后姿态误差 | 7.91° | 7.77° |

该单次对照中线速度 RMS 降低约 19%，角速度 RMS 降低约 8%。仍有残余运动，不能将其称为稳定保持已经解决。

为核对原生伴随中的速度梯度，另将其他代价权重置零，在非零目标线/角速度下抽查四个控制维度。解析梯度与完整原生 rollout 的有限差分最大相对差异为 1.42%。有限差分仅用于验证，不在优化热路径中使用。数值见 [summary.json](summary.json)。

## 完整 5.4 s 示例

同一 seed、8 个起点、每窗口一次 hand 更新：

| 版本 | 最后位置误差 | 最后姿态误差 | 末秒线速度 RMS | 末秒角速度 RMS |
| --- | ---: | ---: | ---: | ---: |
| 之前的默认实现 | 67.64 mm | 18.61° | 0.07295 m/s | 0.32513 rad/s |
| 仅加入速度目标 | 45.81 mm | 16.47° | 0.05699 m/s | 0.18371 rad/s |
| 速度目标 + 任务优先修正 + 力投影修正 | 21.06 mm | 11.06° | 0.05581 m/s | 0.16463 rad/s |

![物体跟踪误差](comparison.png)

最后一行包含多项改动，不能全部归因于速度目标。默认 CUDA 接触流水线平均约 1.57 ms（去除首窗口，包含小量统计回读）；整个 hand/MPC 窗口仍需另行计时。完整运行记录见 [full_runs.json](full_runs.json)。

复现速度对照及原生梯度核对：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python scripts/benchmark_task_velocity.py --output reports/task_velocity_new
python -m pytest -q
```

56 项测试通过，覆盖参考速度与位姿导数一致性、四元数符号、世界/局部角速度变换、参考暂停及终点归零、Warp 损失梯度、SQP 速度目标，以及有界任务 wrench 修正与可行后保持。
