# 已接受页面的设计语言

这是工程核对工具的视觉风格；重点是快速比较、定位差异和追溯数据。保持克制而紧凑的布局，主要空间留给可视化。

## 颜色与文字

| 用途 | 默认值 |
|---|---|
| 页面底色 | `#f0f2ed` |
| 正文 | `#152a30` |
| 次要说明 | `#566b6e` |
| 面板 / 控件 | `#ffffff` |
| 边框 | `#c9d1cb` |
| 强调色 | `#006e65` |
| 提示背景 | `#e3ebe4` |
| 误差提示 | `#ab4a19` |

分类色可用紫、蓝、琥珀、青绿、珊瑚、棕的固定序列：`#a84bce #0077c8 #dc8b09 #00a080 #db5c61 #775c35`。跨案例和跨视图维持实体颜色，不随排序改变。附文字 / 编号以便不靠颜色辨认。

标题默认 30 px，`Georgia, 'Noto Serif CJK SC', serif`；正文 14 px，`'Noto Sans CJK SC', 'Microsoft YaHei', sans-serif`；坐标和技术编号使用 `monospace`。使用本地字体降级，不依赖字体 CDN。

## 空间

- 顶部横向内边距约 30 px，页面标题上方可有 12 px 的小型字距标签。
- 工具栏横向排列，允许换行；控件约 36–40 px 高，圆角 4 px。
- 面板间距 12 px，边框 1 px，圆角 5 px，无明显阴影。图表背景白色。
- 主要视图约 540 px 高；窄屏可降到 420 px，双列在约 850 px 以下变单列。
- 指标是少量大数值加小标签，避免用大片卡片挤占图表。
- 明细表 12 px、行内边距约 10 px；表头用次要色，选中行浅绿；宽表水平滚动。

## 结构与显示

标题直接表达比较对象 / 检查任务。第一段只解释能检查什么。工具栏紧邻主视图；状态说明随案例或阶段更新。表格放详细数值、对应关系与数据来源。

对照图默认使用相同范围和真实单位。模型表面低饱和灰色，标注点使用分类色；法向长度固定并说明单位。视角变化不应改写实际数据。默认视图应让主要判断对象占据视图中央并有适当留白，必要时依据实际数据自适应取景。

不要把本例的“36 个抓型”“295 个点”、算法名称、误差阈值、掌面方向或 GPU 型号当作样式的一部分。这些都是领域数据，由新任务决定。
